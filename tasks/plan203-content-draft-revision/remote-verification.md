# 원격 검증

실행 방법과 운영 값은 `fos-home-infra`가 갖는다. 운영 저장소 변경이 필요하면 코디네이터가 별도 담당에 위임한다.

| 선행 조건 | 실행 위치 | 확인할 것 | 기대값 |
| --- | --- | --- | --- |
| 구현 PR의 로컬 검사와 Draft CI 통과 | PR | 리뷰와 공유 파일 통합, 실제 운영 코드 변경량 | 1,500줄 이하 또는 코디네이터가 검토한 분할·예외, 해당 구현과 설계가 같은 PR |
| 신규 표 마이그레이션을 반영할 준비 완료 | 운영 저장소 절차 | 운영 조회 계정의 새 표 권한 | revision 본문 SELECT 권한 없음, 애플리케이션 저장·조회 가능 |
| 구현 PR 머지와 배포 완료 | 운영 저장소 절차 | 합성 사진이 있는 대화의 실제 MCP 생성·조회·CAS 수정과 삭제 | revision 증가, 같은 대화 참조, 추가 분석·외부 WRITE·발행 0회, 삭제 뒤 이전 본문 차단 |
| 실제 왕복 확인 완료 | 이 저장소의 구현 PR | 검증 결과만 기록 | 운영 주소·계정·포트·경로·토큰을 기록하지 않음 |

순수 compiler의 원본 파일 순서 실증과 실제 provider의 한국어 판독 품질은 이 저장 기능의 완료 근거로 주장하지 않는다.
