# 원격 검증

운영 값과 실행 방법은 `fos-home-infra` 가 갖는다. 이 표에는 확인할 것만 적고 홈서버 명령과 값을 적지 않는다.

| 선행 조건 | 시점 | 실행 위치 | 명령 | 기대값 |
|---|---|---|---|---|
| 머지 | PR 뒤 | 운영 Control Plane 설정, 배포 전 | `fos-home-infra` 의 금융 관문 설정 확인 절차 | 허용 목록 값이 비었거나 모든 항목이 `<계좌 순번>:<사용자 메일>` 형식이다. 옛 형식(계좌 순번만)이 남으면 기동이 멈추므로 배포 전에 고친다 |
| 배포 | PR 뒤 | 운영 화면과 대화, 소유자 | 외부 서비스 연결 화면에서 토스 연결 재동기화 뒤 대화에서 주문 준비 한 번 | 관문을 열기 전에는 금융 전송 없이 거절된다. 관문을 연 뒤에는 승인 카드가 계좌 순번과 주문 요약을 보인다. 실제 주문과 취소는 `docs/features/tossinvest-connector.md` 의 「첫 실제 호출 절차」 를 소유자가 따른다 |
