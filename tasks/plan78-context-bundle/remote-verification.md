# 배포 뒤 확인

Hermes 와 주고받는 것을 바꿨으므로 배포한 뒤 실제 실행을 왕복시켜 본다(루트 `AGENTS.md` 「Hermes 연동을 바꿨으면 배포 뒤 왕복시켜 본다」).
실행 방법은 `fos-home-infra` 가 갖는다.

| 선행 조건 | 확인 | 기대 |
| --- | --- | --- |
| 배포 뒤 | 위임 결과가 오는 자동 turn 하나를 끝낸다 | 답이 정상으로 끝나고, 관리자 실행 상세의 「실은 문맥」 에 `DELEGATION_RESULT` 참조가 보인다 |
| 배포 뒤 | `memory_read` 를 부르는 turn 하나를 끝낸다 | 작업 과정의 `memory_read` 완료 사건에 Memory 본문이 없다 |
| 배포 뒤 | 관리자 사용량 화면을 연다 | 「첫 반응 시간」 절에 최근 날짜 줄이 보인다 |
