# 원격 검증

실제 명령과 접속은 `fos-home-infra` 가 갖는다. 여기에는 무엇을 확인할지만 적는다.

| 선행 조건 | 실행 위치 | 명령 | 기대값 |
|---|---|---|---|
| 머지 뒤 Control Plane 배포 | 운영 웹 화면 | 사진 열한 장 이상을 붙여 보낸다 | 답이 모든 사진의 내용을 말하고, 그 실행에 413 과 `invalid_image_url` 이 없으며, `vision_analyze` 도구 사건이 없거나 작은 글씨를 다시 본 몇 건뿐이다 |
| 머지 뒤 Control Plane 배포 | 운영 웹 화면 | 사진 서른 장을 붙여 보낸다 | 서른 장 모두 입력에 실리고, 실행 시작이 크게 늦지 않다 |
| 머지 뒤 Control Plane 배포 | 운영 웹 화면 | 다음 메시지로 앞 메시지의 사진 여러 장을 묻는다 | `vision_analyze` 를 한 장씩 차례로 부르고, 잘림 오류가 없다 |
