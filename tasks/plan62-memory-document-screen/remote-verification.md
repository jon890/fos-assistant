# 원격 검증

실행 방법은 비공개 저장소 `fos-home-infra` 가 갖는다. 여기에는 확인할 것만 적는다.
**실제 신원 문서는 아래 확인이 모두 끝난 뒤에 넣는다.** 확인에는 지어낸 본문을 쓴다.

| 선행 조건 | 실행 위치 | 명령 | 기대값 |
|---|---|---|---|
| 배포한 뒤 | 브라우저 | `/memory` 에서 영역 「신원」 에 민감 문서를 지어낸 본문으로 만든다 | 목록에 「민감」 표시와 「1번째 판」 이 보인다 |
| 위 문서를 만든 뒤 | 홈서버 | `fos-home-infra` 의 데이터베이스 조회 절차로 그 문서의 `content` 와 `content_key_id` 를 본다 | `content` 가 `v1.` 으로 시작하고 넣은 본문을 담지 않는다. `content_key_id` 가 채워져 있다 |
| 위 문서를 만든 뒤 | 브라우저 | 「외부 서비스 연결」 에서 영역 「신원」 과 민감 허용으로 토큰을 만든다 | 토큰이 한 번 보이고 새로고침하면 사라진다 |
| 토큰을 만든 뒤 | 홈서버 밖의 기기 | 그 토큰으로 서비스 읽기 경로를 부른다. 주소는 `fos-home-infra` 가 갖는다 | 200 이고 `content` 가 넣은 본문, `revision` 이 1 이다 |
| 화면에서 문서를 고친 뒤 | 홈서버 밖의 기기 | 같은 경로를 다시 부른다 | `revision` 이 2 다 |
| 토큰을 폐기한 뒤 | 홈서버 밖의 기기 | 같은 경로를 다시 부른다 | 401 이다 |
| 확인이 끝난 뒤 | 브라우저 | 확인에 쓴 문서와 토큰을 지우고 폐기한다 | 목록에 남지 않는다 |
