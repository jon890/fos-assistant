# 원격 검증

명령과 접속 방법은 운영 저장소 `fos-home-infra` 의 확인 절차가 갖는다. 여기에는 무엇을 확인하는지만 적는다.

| 선행 조건 | 시점 | 실행 위치 | 명령 | 기대값 |
|---|---|---|---|---|
| 배포 | PR 뒤 | 운영 | 운영 저장소의 「커넥터 확인」 절차 | 이미 붙어 있던 로컬 커넥터들의 연결 확인이 통과하고 바인딩이 `READY` 로 남는다. 대시보드 로그에 manifest 를 버렸다는 경고가 새로 없다 |

원격 서버 정의(`url`, `headers`)를 운영 Hermes 가 받아 도구를 등록하고 실제 실행을 왕복하는지는 이 plan 에서 확인하지 않는다. 운영에 원격 플러그인이 아직 없어서다. 그 확인은 뒤로 미룬 금융 워크벤치 전환 PR 이 맡는다.
