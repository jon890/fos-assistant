# Phase 06. 「그룹 단계 설정」 을 무엇을 정하는 곳인지 알 수 있게 고친다

**Execution profile**: standard

## 목표

관리자가 모델 단계 설정 창의 그룹 절을 보고 무엇을 정하는지 알 수 있게 이름, 설명, 배치를 고친다.
사용자가 「그룹 단계 설정」 이 무슨 역할인지 모르겠다고 했다.

**범위 외**: 새 화면, 새 색, 새 API 를 만들지 않는다. 저장하는 값과 요청 모양은 그대로다. 입력 칸의 종류(`Input`, `NativeSelect`)를 바꾸지 않는다.

## 컨텍스트

- `web/src/components/chat/model-picker.tsx` 의 모델 단계 설정 창(`DialogTitle` 「모델 단계 설정」) 안에 관리자에게만 보이는 그룹 절이 있다.
  - 여는 단추와 창 제목이 「그룹 단계 설정」, 닫기 라벨이 「그룹 단계 설정 닫기」, 설명이 「다음 실행부터 각 단계에 이 모델과 강도를 적용해요.」 다.
  - 창 안은 단계마다 `fieldset`(모델 제공사, 모델, 강도 `Input`)이 먼저 오고, 맨 아래에 「그룹 기본값」 `NativeSelect` 가 있다.
  - `needsTierSetup` 이면 「단계 설정이 필요해요. 그룹 단계 설정에서 모델과 강도를 정해 주세요.」 와 「단계 설정이 필요해요. 비워 두면 에이전트 기본값으로 실행해요.」 를 보인다.
  - 저장 실패 문구가 「그룹 단계 설정을 저장하지 못했어요. 잠시 뒤 다시 시도해 주세요.」 다.
- 「내 기본값」 창의 설명은 「새 대화에서 먼저 쓸 단계를 고르세요.」 다. `state.data.groupDefaultTier` 와 `tiers`(단계 코드와 `label`)가 같은 컴포넌트에 있다.
- 화면 문구는 해요체이고 제목은 명사구다(`web/AGENTS.md` 의 「화면 문구」). provider 는 화면에서 「모델 제공사」 라고 쓴다.
- 이 문구를 기대하는 브라우저 검사는 `test/browser/model-choice.spec.ts` 다.

**근거 문서**: `docs/model-tiers.md` 머리말의 「그룹 모델 설정」 문단과 「모델 선택」 절

## 의도 메모

- 이름에 「단계 설정」 만 있으면 그룹 기본 단계를 정하는 곳인지 단계의 모델을 정하는 곳인지 알 수 없다. 두 가지를 절 제목으로 나눠 보인다.
- 사람들이 먼저 궁금한 것은 「따로 고르지 않으면 무엇으로 도는가」 다. 그래서 그룹 기본 단계를 위로 올린다.

## 작업 항목

### 1. `web/src/components/chat/model-picker.tsx` 의 그룹 절

- 여는 단추와 창 제목을 「그룹 모델 설정」 으로, 닫기 라벨을 「그룹 모델 설정 닫기」 로 바꾼다.
- 창 설명을 「이 그룹 사용자가 어느 단계로 시작하는지와 각 단계가 어떤 모델로 도는지 정해요. 저장하면 다음 실행부터 적용돼요.」 로 바꾼다.
- 창 안의 순서를 바꾼다.
  1. 절 제목 「그룹 기본 단계」(`h3`, 창의 다른 절 제목과 같은 클래스)와 설명
     「따로 고르지 않은 사용자는 이 단계로 돌아요. 각자 「내 기본값」 을 정하면 그것이 먼저예요.」, 그 아래 기존 `NativeSelect`.
     `label` 글자는 「그룹 기본 단계」 로 바꾸고 `<option value="">` 의 글자는 「없음 (에이전트 기본 모델로 돌아요)」 로 바꾼다.
  2. 절 제목 「단계별 모델」 과 설명
     「빠르게, 균형, 깊게를 골랐을 때 실제로 도는 모델과 강도예요. 비워 둔 단계는 에이전트 기본 모델로 돌아요.」, 그 아래 기존 단계 `fieldset` 셋.
     「모델 제공사」 `Input` 아래에 도움말 「비워 두면 에이전트의 기본 모델 제공사를 써요.」 를 `text-xs text-muted-foreground` 로 둔다.
- `needsTierSetup` 안내 둘을 바꾼다.
  - 바깥: 「단계별 모델을 아직 정하지 않았어요. 그룹 모델 설정에서 모델과 강도를 정해 주세요.」
  - 창 안: 「단계별 모델을 아직 정하지 않았어요. 비워 두면 에이전트 기본 모델로 돌아요.」
- 저장 실패 문구를 「그룹 모델 설정을 저장하지 못했어요. 잠시 뒤 다시 시도해 주세요.」 로 바꾼다.

### 2. 같은 파일의 「내 기본값」 창

- 설명을 그룹 기본 단계가 있으면 「새 대화에서 먼저 쓸 단계를 고르세요. 정하지 않으면 그룹 기본 단계({단계 이름})로 돌아요.」 로,
  없으면 「새 대화에서 먼저 쓸 단계를 고르세요. 정하지 않으면 에이전트 기본 모델로 돌아요.」 로 보인다.
  단계 이름은 `tiers` 에서 `state.data.groupDefaultTier` 와 같은 줄의 `label` 이다.

### 3. 이 phase 를 검증하는 `test/browser/model-choice.spec.ts`

- 「그룹 단계 설정」 을 이름으로 찾는 단추, 창, 닫기 라벨, 저장 실패 문구, 「단계 설정이 필요해요.」 단언, `getByLabel("그룹 기본값")` 을 새 문구로 고친다. 단언을 지우지 않는다.
  절 제목과 `label` 이 같은 글자(「그룹 기본 단계」)가 되므로 제목은 `getByRole("heading")` 으로, 선택 칸은 `getByLabel` 로 찾는다.
- 관리자가 그룹 모델 설정 창을 열면 「그룹 기본 단계」 와 「단계별 모델」 제목이 보이고, 「그룹 기본 단계」 가 「단계별 모델」 보다 위에 있다(두 제목의 `boundingBox().y` 를 견준다).
- 그룹 기본 단계가 있는 응답에서 「내 기본값」 창의 설명이 그 단계 이름을 담는다. 없는 응답에서는 「에이전트 기본 모델로 돌아요」 를 담는다.
  이 파일이 `model-tiers` 응답을 준비하는 기존 방식을 따른다.
