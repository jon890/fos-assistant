# 원격 검증

| 선행 조건 | 실행 위치 | 명령 | 기대값 |
|---|---|---|---|
| 머지와 배포 뒤 | 운영 화면에서 사진 한 장(3MB 이상)을 붙여 보낸다. 조회 방법은 운영 저장소가 갖는다 | 그 실행의 도구 사건과 답을 본다 | 답이 사진 내용을 말하고 도구 사건에 `vision_analyze` 가 없다 |
| 머지와 배포 뒤 | 같은 실행의 상태와 Hermes 로그 | 실행 상태와 오류 본문을 본다 | `completed` 이고 413, `invalid_image_url`, `unsupported_content_type` 이 없다 |
| 머지와 배포 뒤 | 같은 대화에서 다음 메시지로 앞 사진을 묻는다 | 그 실행의 도구 사건을 본다 | `vision_analyze` 로 그 사진의 `.small.jpg` 사본을 본다 |
| 머지와 배포 뒤 | 사진 열한 장 이상(3MB 넘는 원본 포함)을 한 메시지로 보낸다 | 그 실행의 도구 사건과 Hermes 로그를 본다 | 11번째부터 `.small.jpg` 경로로 `vision_analyze` 를 부르고 「image file is truncated」 가 없다 |
| 머지와 배포 뒤 | 운영 저장소의 첨부 확인 절차 | 새로 올린 사진 폴더를 본다 | 원본 옆에 `.small.jpg` 가 있고, 그 사진을 지우면 둘 다 없어진다 |
