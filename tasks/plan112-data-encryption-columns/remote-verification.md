# 원격 검증

명령과 접속 방법은 운영 저장소 `fos-home-infra` 의 확인 절차가 갖는다. 여기에는 무엇을 확인하는지만 적는다.

| 선행 조건 | 실행 위치 | 명령 | 기대값 |
|---|---|---|---|
| 이 계획을 배포하고 KEK 를 넣은 뒤 | 운영 | 운영 저장소의 「저장 시 암호화 확인」 절차 | 다섯 칸의 평문 줄 수가 매분 줄다가 0 이 되고, 화면의 지난 대화와 작업이 평문으로 보인다 |
| 위와 같다 | 운영 | 운영 조회 계정으로 `chat_message.content` 를 고른다 | 권한이 없다고 거절된다 |
