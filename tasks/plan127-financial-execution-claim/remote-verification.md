# 원격 검증

이번 계획의 승인은 mock 검증으로 끝낸다. 실제 매수와 매도, 정정과 취소는 금지한다.
실행 원문·summary·scope의 공통 vector, 실제 dashboardToken 키 유도와 DB 일회성 소비를 로컬에서 검사한다. 금융 정책은 계속 차단한다.

| 선행 조건 | 실행 위치 | 확인 항목 | 기대값 |
| --- | --- | --- | --- |
| 구현 PR과 로컬 검사 완료 | Draft CI | 크기, 회귀와 공개 정보 검사 | 필수 검사 통과, 운영 코드 1000줄 이하 |
| 별도 배포 dispatch | 운영 저장소가 소유한 환경 | 새 plugin과 CP의 읽기 전용 계약 확인 | 보호 계약이 없는 배포 조합은 금융 차단 |

운영 명령과 환경값은 fos-home-infra가 소유한다. 이 계획은 실제 거래 왕복을 허가하지 않는다.
