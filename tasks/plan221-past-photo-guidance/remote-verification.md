# 원격 검증

실행 방법과 접속 값은 운영 저장소 `fos-home-infra` 가 갖는다. 명령 칸에는 이 저장소의 명령만 적는다.

| 선행 조건 | 시점 | 실행 위치 | 명령 | 기대값 |
|---|---|---|---|---|
| 배포 | PR 뒤 | 홈서버, 운영 저장소의 평가 실행 스크립트 | `node test/model-eval/blog/run.ts send --out <디렉터리>` 뒤 `node test/model-eval/blog/run.ts score --out <디렉터리> --log <파일>` | 네 시나리오가 모두 셋 중 셋 `PASS` 다. 종료 코드 0 이다. 고치기 전 기준값과 함께 결과를 `docs/features/naver-blog-connector.md` 의 「블로그 사진 평가」 에 측정 날짜와 적는다 |
| 배포 | PR 뒤 | 홈서버, 운영 저장소의 평가 실행 스크립트 | 사용자 동의를 받은 비공개 재현을 고치기 전과 같은 시나리오 파일로 다시 돌린다 | 사진 조회와 되묻지 않음이 통과한다. 미리보기를 관리자가 읽고 사진 내용이 반영됐는지 확인한다. 임시 디렉터리와 결과 디렉터리를 지운다 |
