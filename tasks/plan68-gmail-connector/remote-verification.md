# 원격 검증

명령은 적지 않는다. 배포와 홈서버 확인의 방법은 운영 저장소가 갖는다.

| 선행 조건 | 실행 위치 | 명령 | 기대값 |
|---|---|---|---|
| 머지한 뒤 대시보드 plugin 을 Control Plane 보다 먼저 올린다 | 운영 저장소의 배포 절차 | 운영 저장소가 갖는다 | 옛 Control Plane 이 `grant` 가 든 카탈로그를 읽어도 기존 커넥터의 연결이 `READY` 로 남는다 |
| 배포한 뒤 | 웹의 대화 화면 | 기존 커넥터의 쓰기 도구를 한 번 승인해 실행한다 | 승인 카드가 뜨고 승인한 인자로 한 번 실행된다. `AGENTS.md` 의 「Hermes 연동을 바꿨으면 배포 뒤 왕복시켜 본다」 |
| 운영자가 커넥터 목록에 `gmail` 을 올리고 사용자가 토큰을 등록한 뒤 | 웹의 연결 화면과 대화 화면 | `docs/connectors/gmail.md` 의 「실제 계정으로 확인하기」 아홉 단계 | 표의 기대값 그대로 |
