# 원격 검증

실행 방법은 비공개 저장소 `fos-home-infra` 가 갖는다. 여기에는 확인할 것만 적는다.
화면이 plan62 에서 나오므로, 사람이 문서를 넣고 토큰을 발급해 읽어 보는 확인은 그 plan 의 목록에 있다.

| 선행 조건 | 실행 위치 | 명령 | 기대값 |
|---|---|---|---|
| 배포한 뒤 | 홈서버 | `fos-home-infra` 의 배포 확인 절차 | 컨테이너가 새로 만들어졌고 기동 로그에 `Started Assistant` 가 있으며 `Schema validation` 이 실패하지 않는다 |
| 같은 배포 뒤 | 홈서버 밖의 기기 | 토큰 없이 서비스 읽기 경로를 부른다. 주소는 `fos-home-infra` 가 갖는다 | 401 이고 본문이 없다 |
