# plan69-admin-area

관리자 영역(`/admin`)을 일반 화면과 나누고, `MEMBER` 역할에게 가는 응답에서 내부 값을 뺀다.
결정은 `docs/adr/ADR-060-관리자-전용-표시와-동작은-관리자-영역에만-두고-일반-경로의-응답은-서버가-역할에-따라-줄인다.md` 가 갖는다.

## 순서

phase 는 번호 순서로 한다. 한 PR 로 올린다.

| phase | 무엇 | 층 |
| --- | --- | --- |
| 01 | `MEMBER` 역할 응답에서 내부 값을 뺀다 | backend, web 의 타입 |
| 02 | 관리자 영역의 틀, 입구, 사이드바 구역, 역할을 읽지 못했을 때 | web |
| 03 | 에이전트 관리와 커넥터 연결 확인을 옮긴다 | web |
| 04 | 사용량과 실행 상세를 옮기고 일반 화면의 관리자 표시를 끈다 | web |
| 05 | 그룹 모델 설정과 모델 숨김을 `/admin/models` 로 옮긴다 | web |

## 모든 phase 에 걸리는 규칙

- 새 색과 새 디자인 토큰을 만들지 않는다. `web/AGENTS.md` 의 「색과 간격은 테마 토큰이 소유한다」 와 「화면 문구」 를 따른다
- 화면 문구에 특정 그룹이나 가족을 뜻하는 이름을 넣지 않는다
- 관리자 API 경로(`/api/v1/admin/**`, web 의 `/api/admin/**`)와 그 권한 검사를 바꾸지 않는다
- 브라우저 검사는 고친 화면과 관련된 spec 만 돌린다. 전체는 PR 의 CI 가 돌린다
- 문서와 주석에 「나무」, 「뿌리」 를 새로 쓰지 않는다. 「실행 트리」, 「루트」 로 쓴다
- 기능 변경과 포맷 변경을 다른 커밋으로 나눈다. `cd web && pnpm format:changed` 가 고친 것은 따로 커밋한다
