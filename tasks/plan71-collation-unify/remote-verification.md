# 원격 검증

실행 방법은 비공개 저장소 `fos-home-infra` 가 갖는다. 여기에는 확인할 것만 적는다.
**이 변경은 다른 PR 과 묶지 않고 단독으로 배포한다.**

| 선행 조건 | 실행 위치 | 명령 | 기대값 |
|---|---|---|---|
| 머지하기 직전 | 홈서버 | `fos-home-infra` 의 데이터베이스 조회 절차로, 문자열 칸이 든 유일 색인마다 새 정렬 규칙에서 같아지는 줄 묶음을 센다 | 모두 0 이다. 0 이 아니면 머지하지 않는다 |
| 배포하는 동안 | 홈서버 | `fos-home-infra` 의 배포 절차. 덤프와 운영 데이터 복사본 사전 실행이 그 안에 있다 | 사전 실행이 V58 부터 V65 까지를 성공으로 끝낸다 |
| 배포한 뒤 | 홈서버 | `fos-home-infra` 의 배포 확인 절차 | 기동 로그에 `Started Assistant` 가 있고 `Schema validation` 이 실패하지 않는다 |
| 같은 배포 뒤 | 홈서버 | `fos-home-infra` 의 데이터베이스 조회 절차로 표와 문자열 칸의 정렬 규칙을 센다 | `flyway_schema_history` 를 뺀 모든 표와 칸이 `utf8mb4_0900_ai_ci` 다. Flyway 이력의 마지막 번호가 65 이고 실패한 줄이 없다 |
| 같은 배포 뒤 | 브라우저 | 대화를 하나 보내고 실행 기록을 연다 | 응답이 오고 실행 기록에 도구 사건이 보인다 |
