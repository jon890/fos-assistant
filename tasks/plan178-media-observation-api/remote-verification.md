# 원격 검증과 발행 책임

| 선행 조건 | 책임·실행 위치 | 확인할 결과 |
| --- | --- | --- |
| 코디네이터의 독립 critic 검토 후 구현·로컬 검사 완료 | 명시적으로 배정한 구현 담당자와 publisher | 설계와 구현을 같은 브랜치에 담고 계획서를 지운 뒤 Draft PR을 연다. 계획만 commit/push/PR 하지 않는다 |
| 실제 publisher가 PR 발행 작업을 맡음 | 해당 브랜치 | 루트의 pr-merge 스킬과 create-pr 스킬을 읽고 main 일반 merge·전체 CI·규모/공개정보 검사·Claude 리뷰 한 번 반영을 지킨다 |
| backend 배포 뒤 fos-ctx를 사용하는 profile에 설치 완료 | 별도 권한을 받은 운영 담당자, fos-home-infra 절차 | 실제 Hermes 실행의 두 도구가 서명되어 현재 대화의 합성 사진 관찰을 기록·조회하고 native 이미지 경로를 유지한다 |
| 위 왕복이 성공함 | 같은 운영 담당자 | USER 정정 뒤 MODEL 거절, 실행 취소·session/profile 접근 철회, 사건 본문 가림을 확인한다. 본문·토큰·운영 값은 공개 결과에 넣지 않는다 |

planner는 문서·계획만 변경한다. 운영·provider·실계정 네이버 임시저장 권한은 이 계획에 포함되지 않는다.
전체 사진·원고·미리보기·승인·임시저장 흐름 검증은 이 API 관심사의 완료 판정으로 대신하지 않는다.
운영 명령과 환경 값은 이 저장소에 적지 않는다.
