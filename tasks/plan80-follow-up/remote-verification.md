# 원격 검증

Hermes 와 주고받는 도구를 더했으므로 배포한 뒤 실제 실행을 한 번 왕복시킨다(루트 `AGENTS.md` 의 「Hermes 연동을 바꿨으면 배포 뒤 왕복시켜 본다」).
배포 방법과 운영에 붙는 방법은 비공개 저장소 `fos-home-infra` 가 갖는다. 여기에는 무엇을 확인하는지만 적는다.

| 선행 조건 | 실행 위치 | 명령 | 기대값 |
| --- | --- | --- | --- |
| fos-ctx plugin 을 배포한 뒤 | 운영 Hermes profile | 운영 저장소의 plugin 확인 절차로 그 profile 의 `fos-ctx` 버전에 `follow_up_propose` 가 서명 필수 도구로 들었는지 본다 | 들어 있다 |
| Control Plane 을 배포한 뒤 | 웹 화면의 대화 | 지어낸 일(「할 일 검사 7391 을 금요일까지 해야 해」)로 에이전트에게 할 일 제안을 부탁한다 | 답이 할 일로 제안했다고 말하고, `GET /api/v1/follow-ups` 에 그 대화의 `PROPOSED` 줄이 하나 생긴다 |
| 위 확인 뒤 | 같은 대화 | 같은 부탁을 한 번 더 한다 | 새 줄이 생기지 않는다 |
| 위 확인 뒤 | Control Plane 로그 | 그 시각의 `follow-up` 로그 줄을 본다 | 사용자 번호, 실행 번호, 결과만 있고 제목이 없다 |
| 확인을 마친 뒤 | 웹 화면이나 API | 검사로 만든 할 일을 `reject` 한다 | `REJECTED` |
