# 네이버 블로그 커넥터

내 네이버 블로그의 임시저장 글을 비서의 에이전트와 함께 읽고 고쳐요.
에이전트가 글을 쓰거나 고치면 임시저장까지만 하고, 발행은 하지 않아요. 공개는 내가 네이버에서 직접 해요.

## 할 수 있는 일

- 임시저장 글 목록을 보고, 글 하나를 골라 읽어요
- 쓸 글을 저장하기 전에 모바일 화면처럼 미리 봐요
- 승인한 글을 네이버 블로그에 새 임시저장 글로 만들어요. 사진과 스티커, 지도도 넣을 수 있어요
- 읽은 임시저장 글을 승인한 내용으로 고쳐요. 고치기 전 원래 글은 사본으로 남아요
- 글을 발행하거나 지우지는 않아요

임시저장 글을 읽거나 새로 저장하거나 고칠 때는 승인 카드가 떠요. 읽기와 고치기는 「이 대화에서 계속 허용」을 고르면 그 대화에서 24시간까지 카드 없이 돼요. 새로 저장하기는 상시 허락을 줄 수 있고, 주면 그 기간에는 카드 없이 저장돼요.
카드에서 제목과 본문, 바뀌는 내용을 읽고 승인해 주세요.
카드에 「가려진 내용이 있어 승인할 수 없어요」가 보이면 거절하고, 그 부분을 빼거나 풀어 써 달라고 에이전트에게 말해 주세요.

## 연결하는 방법

처음 한 번만 하면 돼요. 네이버 계정과 블로그 아이디가 필요해요.

1. 「내 브라우저」 화면에서 브라우저를 켜고 네이버에 로그인해요. 「외부 서비스 연결」 화면의 「내 브라우저에서 로그인」 링크를 누르면 네이버 로그인 화면이 바로 열려요. 비밀번호와 인증번호는 대화에 붙여 넣지 말고 로그인 화면에 직접 입력해요
2. 「로그인 상태 유지」를 켜 두면 브라우저를 다시 켜도 로그인이 남을 수 있어요
3. 「외부 서비스 연결」에서 네이버 블로그를 골라 블로그 아이디를 넣어요. 아이디는 `blog.naver.com/` 뒤에 오는 값이에요
4. 브라우저가 꺼져 있었다면 켜지는 동안 첫 확인이 실패할 수 있어요. 잠시 뒤 「연결 다시 확인」을 눌러요
5. 연결되면 글을 쓸 에이전트의 화면을 열고 「이 에이전트가 쓰는 연결」에서 네이버 블로그를 붙여요. 그 에이전트는 비공개여야 해요
6. 몇 분 안에 저절로 반영돼요. 그 사이에는 「반영 대기」로 보여요

내 블로그의 말투나 카테고리별로 담을 내용은 에이전트의 기억에 남겨 두면 글을 쓸 때마다 읽어 써요.

## 도구 목록

| 도구 | 하는 일 |
| --- | --- |
| 로그인 상태 확인 | 내 브라우저에 연결되는지와 네이버에 로그인돼 있는지 확인해요. 글을 저장하거나 새 탭을 열지 않아요. |
| 임시저장 글 목록 보기 | 네이버 블로그의 임시저장 글 제목과 고친 시각을 앞쪽 200개까지 읽어요. 읽는 동안 내 브라우저에 글쓰기 탭이 잠깐 열려요. |
| 임시저장 글 불러오기 | 임시저장 글 하나를 편집기에 불러와 제목과 본문을 읽어요. 불러오는 동안 네이버가 자동저장을 할 수 있어서 승인 카드가 떠요. |
| 글 미리 보기 | 쓸 글을 모바일 화면처럼 미리 보여 줘요. 네이버에는 저장하지도 발행하지도 않아요. |
| 네이버 블로그에 임시저장 | 승인한 글을 네이버 블로그에 새 임시저장 글로 만들어요. 발행하지 않아요. 저장하기 전에 승인 카드가 떠요. |
| 네이버 블로그 임시저장 글 덮어쓰기 | 미리 본 임시저장 글을 승인한 내용으로 고쳐요. 고치기 전 원래 글은 사본으로 남아요. |
| 임시저장 진행 확인 | 임시저장이나 덮어쓰기가 끝났는지 확인해요. 결과를 알 수 없다고 나오면 다시 저장하기 전에 목록부터 봐요. |

## 문제가 생겼을 때

| 증상 | 할 일 |
| --- | --- |
| 로그인이 필요하다고 하거나 「연결 다시 확인」이 실패해요 | 「내 브라우저」에서 네이버에 다시 로그인하고, 「외부 서비스 연결」에서 연결을 다시 확인해요 |
| 브라우저에 닿지 못한다고 해요 | 「내 브라우저」가 켜져 있는지 보고, 꺼져 있으면 켠 뒤 잠시 기다렸다가 다시 시도해요. 켜는 데 30초쯤 걸려요 |
| 다른 저장 작업이 진행 중이라고 해요 | 같은 블로그의 저장 작업은 하나씩만 돌아요. 앞 작업이 끝난 뒤 다시 시도해요 |
| 글쓰기 화면이 쓰는 중이라고 해요 | 네이버 글쓰기 화면에 작성 중인 글이 열려 있어요. 그 탭을 직접 저장하거나 닫은 뒤 다시 시도해요 |
| 저장했는지 알 수 없다고 해요 | 바로 다시 저장하지 말고, 네이버의 임시저장 목록에 글이 생겼는지 먼저 확인해요 |
| 덮어쓰기가 실패했어요 | 고치기 전 원래 글이 사본으로 남아 있을 수 있어요. 네이버 임시저장 목록에서 `[덮어쓰기 전 원본]`으로 시작하는 글을 확인해요 |
| 값을 바꿔 다시 등록했더니 「반영 대기」가 풀리지 않아요 | 관리자에게 반영 완료를 부탁해요 |

**연결을 끊으려면** 「외부 서비스 연결」에서 해제해요. 비서 쪽의 값만 지워지고, 「내 브라우저」의 네이버 로그인은 남아요. 로그인도 지우려면 네이버에서 로그아웃해 주세요.
