# 코레일 KTX 플러그인

「내 브라우저」 로 코레일 화면에서 KTX 열차를 한 번 조회하는 플러그인이다.
개발 문서는 [코레일 KTX 플러그인](../../../docs/features/korail-ktx.md) 이 갖는다.

## 할 수 있는 일

- 출발역, 도착역, 날짜와 시각, 인원, 좌석 종류로 코레일에서 열차를 한 번 조회한다
- 첫 화면의 KTX 계열 열차와, 코레일에서 함께 보이는 수서발 SRT 열차를 보인다

**예매하거나 결제하지 않는다.** 좌석 확보와 결제 화면 넘기기는 다음 버전에서 더한다.
취소표를 되풀이해 찾거나 예약해 둔 시각에 조회하지 않는다. 사람이 연 대화에서만 쓴다.

**코레일은 매크로를 탐지해 예매를 제한할 수 있다.** 철도회원 약관상 적발되면 예매가 제한되고, 거듭되면 탈퇴될 수 있다. 이 위험을 알고 쓴다.

## 연결하는 방법

1. 「내 브라우저」(`/browser`)에서 코레일에 로그인한다
2. 「외부 서비스 연결」 화면에서 코레일 KTX 를 연결한다. 넣을 칸은 없다
3. 쓸 에이전트에 붙인다

## 도구 목록

| 도구 | 하는 일 |
| --- | --- |
| 코레일 연결 확인 | 내 브라우저에 연결되는지와 코레일을 연 적이 있는지 확인해요. 새 탭을 열지 않아요. |
| KTX 열차 조회 | 출발역, 도착역, 날짜와 시각, 인원으로 코레일에서 KTX 열차를 한 번 조회해요. 조회하는 동안 내 브라우저에 새 탭이 잠깐 열려요. |

## 문제가 생겼을 때

- **로그인, 매크로 탐지, 보안 문자 화면이 떴다**: 플러그인은 아무것도 누르지 않고 멈춘다. 「내 브라우저」 를 열면 그 화면의 탭이 남아 있다. 직접 풀고 다시 요청한다
- **모르는 역이라는 오류**: 역 이름을 코레일에 나오는 이름 그대로 말한다(예: 「김천구미」, 「광주송정」)
- **화면이 바뀌었다는 오류**: 코레일 화면의 구조가 바뀌었을 수 있다. 관리자에게 알린다
- **브라우저에 닿지 않는다**: 꺼진 브라우저를 켜는 데 30초까지 걸린다. 잠시 뒤 다시 요청한다
