# 네이버 쇼핑 플러그인

「내 브라우저」 에 로그인해 둔 네이버 계정으로 네이버 쇼핑에서 상품을 찾고 상품 정보를 읽으며, 사용자가 승인한 상품 하나를 네이버 주문서까지 채우는 플러그인이다.
개발 문서는 [네이버 쇼핑 플러그인](../../../docs/features/naver-shopping.md) 이 갖는다.

## 할 수 있는 일

- 검색어 하나로 네이버 쇼핑 검색 결과 첫 페이지의 상품을 읽는다
- 상품 하나의 판매처, 가격, 옵션, 배송비를 읽는다. 여러 판매처를 묶은 가격비교 상품은 묶음 이름과 최저가, 배송비만 읽는다(판매처별 가격은 아직 읽지 못한다)
- 다른 쇼핑몰로 넘어가는 상품은 화면을 열지 않고 링크만 보인다
- 사려는 상품 하나와 옵션, 수량으로 승인 카드를 띄우고, 승인하면 「내 브라우저」 에서 네이버 주문서까지 채운다

**결제 단추는 누르지 않는다.** 주문서까지 가면 결제는 사람이 「내 브라우저」 의 주문서 탭에서 직접 하거나 그 탭을 닫는다. 장바구니에는 담지 않는다.
주문서 준비는 「외부 서비스 연결」 화면에서 구매 상한(한 건, 하루)을 0 보다 크게 정해야 열린다. 기본은 0 이라 닫혀 있다.
먼저 살펴보기, 매일 깨우기, 예약 작업에서는 이 플러그인의 도구를 쓰지 않는다. 사람이 연 대화에서만 쓴다.

## 연결하는 방법

1. 「내 브라우저」(`/browser`)에서 네이버에 로그인한다
2. 「외부 서비스 연결」 화면에서 네이버 쇼핑을 연결한다. 넣을 칸은 없다. 연결 확인이 네이버 로그인 쿠키가 있는지 본다
3. 쓸 에이전트에 붙인다

## 도구 목록

| 도구 | 하는 일 |
| --- | --- |
| 로그인 상태 확인 | 내 브라우저에 연결되는지와 네이버에 로그인돼 있는지 확인해요. 새 탭을 열지 않아요. |
| 네이버 쇼핑 상품 찾기 | 검색어 하나로 네이버 쇼핑 검색 결과 첫 페이지의 상품을 40개까지 읽어요. 읽는 동안 내 브라우저에 새 탭이 잠깐 열려요. |
| 상품 정보 보기 | 상품 하나의 판매처, 가격, 옵션, 배송비를 읽어요. 옵션 목록을 보려고 옵션 단추 하나만 눌러요. 다른 쇼핑몰 상품은 열지 않고 링크만 보여 줘요. |
| 주문서 준비하기 | 상품 하나와 옵션, 수량으로 주문 내용을 정리해 승인 카드를 띄워요. 이 단계에서는 주문서를 열지 않아요. |
| 주문서 채우기 | 승인한 상품 하나를 내 브라우저에서 네이버 주문서까지 채워요. 결제 단추는 누르지 않아요. |

## 문제가 생겼을 때

- **로그인, 캡차, 기기 인증 화면이 떴다**: 플러그인은 아무것도 누르지 않고 멈춘다. 「내 브라우저」 를 열면 그 화면의 탭이 남아 있다. 직접 풀고 다시 요청한다
- **화면이 바뀌었다는 오류**: 네이버 화면의 구조가 바뀌었을 수 있다. 관리자에게 알린다
- **브라우저에 닿지 않는다**: 꺼진 브라우저를 켜는 데 30초까지 걸린다. 잠시 뒤 다시 요청한다
- **「상한을 정해 주세요」 로 거절된다**: 「외부 서비스 연결」 의 네이버 쇼핑 연결에서 구매 상한 두 칸을 정한다
- **「내 브라우저에 열린 탭을 확인해 주세요」 카드가 떴다**: 주문서가 열렸는지 알 수 없다는 뜻이다. 플러그인은 다시 시도하지 않는다. 「내 브라우저」 의 탭을 보고 주문서가 있으면 결제하거나 닫는다
