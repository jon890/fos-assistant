# Gmail 커넥터

내 Gmail 계정을 비서의 에이전트에 연결해요.
연결하면 에이전트가 메일을 찾아 읽고, 내가 승인한 메일만 보내요.

## 할 수 있는 일

- 메일을 찾고 읽어요. 받은 메일을 요약하거나 필요한 메일을 찾아 달라고 할 수 있어요
- 초안을 만들어 두거나, 승인을 받은 뒤 메일과 답장을 보내요
- 라벨과 자동 분류 필터로 메일을 정리해요
- 메일을 휴지통에 넣거나 영구히 지우지는 않아요

메일을 보내거나 답장할 때는 매번 승인 카드가 떠요.
받는 사람과 제목, 본문을 읽고 승인해 주세요.
카드에 「가려진 내용이 있어 승인할 수 없어요」가 보이면 거절하고, 그 부분을 빼거나 풀어 써 달라고 에이전트에게 말해 주세요.

## 연결하는 방법

처음 한 번만 하면 돼요. Google 계정과, 브라우저와 Python 3이 있는 컴퓨터가 필요해요.

### 1. Google Cloud에서 OAuth client 만들기

1. [Google Cloud 콘솔](https://console.cloud.google.com/)에서 프로젝트를 하나 만들어요
2. 「API 및 서비스」의 라이브러리에서 **Gmail API**를 찾아 사용 설정해요
3. 「OAuth 동의 화면」을 만들어요. 사용자 유형은 「외부」를 고르고, 자기 조직 안에서만 쓰는 Google Workspace 계정이면 「내부」를 골라요
4. 데이터 액세스에 `https://www.googleapis.com/auth/gmail.modify`와 `https://www.googleapis.com/auth/gmail.settings.basic`을 더해요
5. **게시 상태를 「프로덕션」으로 바꿔요.** 검수는 신청하지 않아도 돼요. 「테스트」 상태로 두면 7일 뒤 연결이 끊겨요
6. 「사용자 인증 정보」에서 OAuth 클라이언트 ID를 만들어요. 애플리케이션 유형은 **데스크톱 앱**이에요
7. 만들어진 클라이언트 ID와 클라이언트 보안 비밀번호(secret)를 적어 둬요

### 2. refresh token 받기

이 저장소의 스크립트를 자기 컴퓨터에서 돌려요.

```bash
# cwd: 저장소 root
python3 hermes/connectors/gmail/scripts/get_refresh_token.py
```

1. 스크립트가 클라이언트 ID와 secret을 물어요. secret은 입력하는 동안 화면에 보이지 않아요
2. 스크립트가 출력한 주소를 브라우저로 열고, 연결할 Google 계정으로 로그인해요
3. 「Google에서 확인하지 않은 앱」 경고가 나오면 「고급」을 눌러 계속해요. 직접 만든 앱이라 나오는 경고예요
4. 메일 권한을 허용하면 터미널에 refresh token이 출력돼요

5분 안에 허용하지 않으면 스크립트가 끝나요. 그때는 다시 돌려 주세요.
refresh token은 그 계정의 메일을 읽고 보낼 수 있는 값이에요. 붙여 넣은 뒤 터미널 기록에서 지워 주세요.

Python을 쓸 수 없으면 [OAuth 2.0 Playground](https://developers.google.com/oauthplayground)로도 받을 수 있어요.
이때는 클라이언트 유형을 「웹 애플리케이션」으로 만들고, 승인된 리디렉션 URI에 Playground 주소를 넣은 뒤 Playground 설정에서 자기 클라이언트를 쓰도록 켜요.
이 방법은 client secret을 Google의 웹 도구에 입력해요.

### 3. 외부 서비스 연결에 넣기

1. 「외부 서비스 연결」에서 Gmail을 골라요
2. 클라이언트 ID, 클라이언트 secret, refresh token을 붙여 넣고 등록해요. 값이 맞으면 계정을 한 번 읽어 본 뒤 저장해요
3. 연결되면 Gmail을 쓸 에이전트의 화면을 열고 「이 에이전트가 쓰는 연결」에서 Gmail을 붙여요. 그 에이전트는 비공개여야 해요
4. 몇 분 안에 저절로 반영돼요. 그 사이에는 「반영 대기」로 보여요

## 도구 목록

| 도구 | 하는 일 |
| --- | --- |
| 계정 정보 보기 | 연결한 Gmail 주소와 전체 메일 수를 읽어요. |
| 라벨 목록 보기 | Gmail에 있는 라벨의 이름과 종류를 읽어요. |
| 메일 찾기 | Gmail 검색어로 메일을 찾아요. 본문은 열지 않고 제목과 보낸 사람, 앞부분만 읽어요. |
| 메일 읽기 | 메일 한 통의 본문을 읽어요. 첨부 파일은 이름과 크기만 보고 열지 않아요. |
| 주고받은 메일 읽기 | 한 메일에 이어진 답장까지 차례로 읽어요. 한 번에 20통까지 읽어요. |
| 초안 만들기 | 보낼 메일을 초안함에 만들어 둬요. 보내지는 않아요. |
| 라벨 바꾸기 | 메일 한 통에 라벨을 붙이거나 떼요. 보관과 읽음 표시도 여기서 하고, 바꿀 때마다 승인해요. |
| 메일 보내기 | 새 메일을 보내요. 보낼 때마다 내용을 보고 승인해요. |
| 답장 보내기 | 받은 메일에 이어서 답장을 보내요. 보낼 때마다 승인해요. |
| 라벨 만들기 | 메일을 분류할 새 라벨을 만들어요. |
| 라벨 설정 바꾸기 | 직접 만든 라벨의 이름이나 색을 바꿔요. Gmail 기본 라벨은 바꾸지 않아요. |
| 필터 목록 보기 | 저장된 자동 분류 필터의 조건과 동작을 읽어요. |
| 필터 만들기 | 앞으로 받는 메일을 자동으로 분류할 필터를 만들어요. 만들 때마다 승인해요. |
| 필터 지우기 | 저장된 필터 하나를 지워요. 메일은 지우지 않고, 지울 때마다 승인해요. |
| 검색한 메일의 라벨 바꾸기 | 검색에 걸린 메일 500통까지 라벨을 한꺼번에 바꿔요. 바꿀 때마다 바뀔 메일 수를 보고 승인해요. |

## 문제가 생겼을 때

| 증상 | 할 일 |
| --- | --- |
| 에이전트가 메일을 읽지 못했다고 하고 「연결 다시 확인」도 실패해요 | 토큰이 만료됐거나 권한이 철회됐어요. 「2. refresh token 받기」를 다시 하고 새 값으로 다시 등록해 주세요 |
| 일주일쯤 지나 연결이 끊겨요 | 동의 화면이 「테스트」 상태예요. 「프로덕션」으로 바꾸고 토큰을 다시 받아 주세요 |
| 필터를 만들거나 지울 때만 권한이 없다고 해요 | 예전에 받은 토큰에 필터 권한이 없어요. 동의 화면의 데이터 액세스에 `gmail.settings.basic`을 더하고, 토큰을 다시 받아 등록해 주세요 |
| 값을 바꿔 다시 등록했더니 「반영 대기」가 풀리지 않아요 | 관리자에게 반영 완료를 부탁해 주세요 |

Google 비밀번호를 바꾸거나 6개월 동안 쓰지 않으면 토큰이 무효가 돼요.
같은 client로 토큰을 아주 여러 번 받으면 오래된 토큰부터 무효가 돼요. 그때도 토큰을 다시 받아 주세요.

**연결을 끊으려면** 「외부 서비스 연결」에서 해제하고, Google 계정의 「보안」에서 「서드 파티 앱 및 서비스」를 열어 직접 만든 앱도 지워 주세요.
해제만 하면 비서 쪽의 값만 지워지고 Google 쪽의 권한은 남아요.
