# 토스증권 커넥터

내 토스증권 계좌를 비서의 에이전트에 연결해요.
연결하면 에이전트가 보유 종목과 시세, 주문 내역을 읽어 알려 줘요.

## 할 수 있는 일

- 보유 종목, 평가 금액과 손익, 주문 가능 현금을 읽어요
- 현재가와 호가, 차트, 환율, 장 운영 일정 같은 시장 정보를 읽어요
- 주문 내역과 조건주문을 읽어요
- **주문하지 않아요.** 사고팔거나 주문을 고치고 취소하는 도구가 없어요. 매매는 토스증권 앱이나 웹에서 직접 해 주세요

모든 도구가 읽기만 해서 승인 카드 없이 바로 실행돼요.
읽은 계좌 정보는 대화에 쓰이도록 모델 제공사에 전달돼요.

## 연결하는 방법

### 1. client 만들기

1. 토스증권 WTS 에 로그인해 설정 > Open API 에서 client 를 만들어요. **이 커넥터 전용 client 를 따로 만들어 주세요.** 같은 client 를 다른 프로그램에서 쓰면 서로의 연결을 끊어요
2. 같은 화면의 허용 IP 관리에 비서가 밖으로 나가는 공인 IP 를 등록해요. 어떤 IP 인지는 관리자에게 물어봐 주세요

### 2. 외부 서비스 연결에 넣기

1. 「외부 서비스 연결」 에서 토스증권을 골라요
2. client ID 와 secret 을 넣으면 계좌 목록이 떠요. 계좌번호는 끝 네 자리만 보여요
3. 읽을 계좌를 고르고 저장해요
4. 자기 비공개 에이전트 **하나**에 붙여요. 안전하게 분리된 실행 공간이 있는 에이전트에만 붙일 수 있어요

## 도구 목록

| 도구 | 하는 일 |
| --- | --- |
| 계좌 목록 보기 | 연결한 토스증권 계좌를 계좌번호 끝 네 자리로 보여 줘요. |
| 현재가 보기 | 여러 종목의 현재가와 이름을 한 번에 읽어요. |
| 종목 정보 보기 | 종목이 상장된 시장과 거래 상태 같은 기본 정보를 읽어요. |
| 시장별 종목 목록 보기 | 코스피나 나스닥 같은 시장에 상장된 종목 목록을 읽어요. |
| 매수 유의사항 보기 | 종목 하나에 걸린 투자 경고 같은 매수 유의사항을 읽어요. |
| 보유 종목 보기 | 계좌에 있는 종목과 평가 금액, 손익을 읽어요. |
| 주문 가능 금액 보기 | 원화나 달러로 주문할 수 있는 현금을 읽어요. 주문은 하지 않아요. |
| 주문 내역 보기 | 체결되지 않은 주문이나 끝난 주문을 기간별로 읽어요. |
| 매도 가능 수량 보기 | 종목 하나를 지금 몇 주까지 팔 수 있는지 읽어요. 주문은 하지 않아요. |
| 호가 보기 | 종목 하나를 사고팔려는 가격과 잔량을 읽어요. |
| 최근 체결 보기 | 종목 하나가 오늘 거래된 최근 가격과 수량을 읽어요. |
| 상한가와 하한가 보기 | 종목 하나의 오늘 상한가와 하한가를 읽어요. |
| 가격 차트 보기 | 종목 하나의 분 단위나 일 단위 가격 흐름과 거래량을 읽어요. |
| 환율 보기 | 원화와 달러 사이의 참고용 환율을 읽어요. 실제 거래 환율과 다를 수 있어요. |
| 장 운영 일정 보기 | 국내나 미국 시장의 전 영업일, 오늘, 다음 영업일 운영 시간을 읽어요. |
| 섹터 목록 보기 | 토스증권이 나눈 업종(섹터) 목록을 읽어요. |
| 섹터 순위 보기 | 기간별로 많이 오르거나 거래가 많은 섹터의 순위를 읽어요. |
| 섹터 정보 보기 | 섹터 하나의 소개와 기간별 등락률을 읽어요. |
| 섹터 종목 보기 | 섹터 하나에 속한 주식 목록을 읽어요. |
| 섹터 ETF 보기 | 섹터 하나와 관련된 ETF 목록을 읽어요. |
| 조건주문 목록 보기 | 진행 중이거나 끝난 조건주문을 읽어요. 새로 걸거나 취소하지 않아요. |
| 조건주문 상세 보기 | 조건주문 하나의 조건과 진행 상태를 읽어요. |
| 종목 순위 보기 | 국내와 미국 주식의 거래대금, 거래량, 급상승, 급하락 순위를 읽어요. |
| 지수와 국채 금리 보기 | 코스피, 코스닥 지수와 한국 국채 금리의 현재 값을 읽어요. |
| 지수와 금리 차트 보기 | 국내 지수와 국채 금리의 기간별 흐름을 읽어요. |
| 시장 투자자별 매매 보기 | 코스피와 코스닥에서 개인, 외국인, 기관이 사고판 금액을 읽어요. |
| 주문 상세 보기 | 주문 하나의 내용과 체결 결과를 읽어요. |
| 수수료 보기 | 시장별 매매 수수료율을 읽어요. |
| 종목 투자자별 매매 보기 | 국내 종목 하나를 개인, 외국인, 기관이 사고판 수량을 읽어요. |
| 프로그램 매매 보기 | 국내 종목 하나의 프로그램 매매 수량을 읽어요. |
| 공매도 보기 | 국내 종목 하나의 공매도 수량과 금액, 비중을 읽어요. |
| 신용거래 보기 | 국내 종목 하나의 개인 신용거래 현황을 읽어요. |
| 대차거래 보기 | 국내 종목 하나를 기관끼리 빌려주고 빌린 현황을 읽어요. |

## 문제가 생겼을 때

| 증상 | 할 일 |
| --- | --- |
| 모든 조회가 허용 IP 를 확인하라는 안내로 실패해요 | 집의 공인 IP 가 바뀌었을 수 있어요. WTS 에서 허용 IP 를 고친 뒤 「외부 서비스 연결」 에서 「연결 다시 확인」 을 눌러 주세요 |
| 두 번째 에이전트에 붙지 않아요 | 토스증권 연결은 에이전트 하나에만 붙일 수 있어요. 앞서 붙인 에이전트에서 먼저 떼어 주세요 |
| 에이전트에 붙지 않고 실행 공간이 없다고 해요 | 안전하게 분리된 실행 공간이 있는 에이전트에만 붙일 수 있어요. 관리자에게 물어봐 주세요 |
| 계좌를 찾지 못한다고 해요 | 고른 계좌가 없어졌어요. 다시 등록해 계좌를 골라 주세요 |
| 잠시 뒤 다시 하라고 해요 | 토스증권의 호출 한도에 걸렸거나 응답이 늦어요. 잠시 뒤 다시 물어봐 주세요 |

**연결을 끊으려면** 「외부 서비스 연결」 에서 해제하고, 토스증권 WTS 에서 그 client 도 지워 주세요.
