# 금융 워크벤치 커넥터

내 금융 온톨로지 워크벤치를 비서의 에이전트에 연결해요.
연결하면 에이전트가 워크벤치에 쌓아 둔 투자 결정과 그 근거를 찾아 읽어요.
토스증권 커넥터와 같은 에이전트에 붙이면 「내 FLNC 보유 현황과 워크벤치의 투자 근거를 같이 보여 줘」 같은 질문에 답해요.

## 할 수 있는 일

- 종목 코드로 워크벤치의 종목과 내 투자 결정, 밸류에이션 시나리오를 읽어요
- 투자 결정에서 병목과 산업, 세상의 변화까지 근거를 거슬러 올라가요
- 항목을 찾고, 한 항목에 이어진 주장과 근거 문서, 주변 항목을 읽어요
- 내가 헷갈린다거나 공부 중이라고 표시한 항목을 읽어요
- 워크벤치에 아무것도 쓰지 않아요. 체결 기록을 워크벤치에 남기는 일은 아직 하지 않아요

모든 도구는 읽기만 해서 승인 카드 없이 바로 실행돼요.
읽은 내용은 대화에 쓰이도록 모델 제공사에 전달돼요.

## 연결하는 방법

워크벤치 주소는 관리자가 넣어 두어요. 나는 연동 토큰만 넣으면 돼요.

### 1. 워크벤치에서 연동 토큰 발급하기

1. 워크벤치에 로그인해 「더보기 → 연동 토큰」을 열어요
2. 이름을 「Hermes」처럼 알아보기 쉽게 적고 발급해요
3. `fwb_`로 시작하는 토큰이 한 번만 보여요. 바로 복사해 두세요. 창을 닫으면 다시 볼 수 없어요

토큰은 한 사람이 5개까지 만들 수 있어요.

### 2. 외부 서비스 연결에 넣기

1. 「외부 서비스 연결」에서 금융 워크벤치를 골라요
2. 연동 토큰을 붙여 넣고 등록해요. 토큰이 맞으면 워크벤치의 내 이름을 한 번 읽어 본 뒤 저장해요
3. 연결되면 워크벤치를 쓸 에이전트의 화면을 열고 「이 에이전트가 쓰는 연결」에서 금융 워크벤치를 붙여요. 토스증권을 붙인 에이전트에 함께 붙여도 돼요
4. 몇 분 안에 저절로 반영돼요. 그 사이에는 「반영 대기」로 보여요

## 도구 목록

| 도구 | 하는 일 |
| --- | --- |
| 연결 확인하기 | 연동 토큰이 맞는지 보고 워크벤치의 내 표시 이름과 토큰 이름을 읽어요. |
| 온톨로지 요약 보기 | 워크벤치에 어떤 종류의 항목과 관계가 있는지 읽어요. |
| 항목 찾기 | 이름이나 종목 코드로 워크벤치의 기업, 산업, 투자 결정, 근거 문서 같은 항목을 찾아요. |
| 항목 자세히 보기 | 항목 하나의 속성과 이어진 관계, 주장, 근거 문서, 개념을 읽어요. |
| 근거 따라가기 | 투자 결정이나 밸류에이션에서 시작해 병목, 산업, 세상의 변화까지 근거를 거슬러 올라가요. |
| 주변 그래프 보기 | 한 항목에서 한두 단계 안에 이어진 항목과 관계를 읽어요. |
| 종목의 투자 근거 찾기 | 종목 코드로 워크벤치의 종목과 내 투자 결정, 밸류에이션 시나리오를 함께 읽어요. |
| 내 공부 목록 보기 | 내가 안다, 헷갈린다, 공부 중이라고 표시한 항목과 메모를 읽어요. |

## 문제가 생겼을 때

| 증상 | 할 일 |
| --- | --- |
| 에이전트가 연동 토큰이 맞지 않는다고 하고 「연결 다시 확인」도 실패해요 | 토큰을 폐기했거나 워크벤치 계정이 꺼졌어요. 워크벤치의 「더보기 → 연동 토큰」에서 새로 발급하고, 「외부 서비스 연결」에서 새 값으로 다시 등록해 주세요 |
| 에이전트가 잠시 뒤 다시 하자고 해요 | 토큰 하나는 1분에 60번까지 불러요. 알려 준 시간만큼 기다린 뒤 다시 물어봐 주세요 |
| 워크벤치를 쓸 수 없다고 해요 | 관리자가 워크벤치 주소를 넣지 않았거나 워크벤치가 멈췄어요. 관리자에게 알려 주세요 |
| 값을 바꿔 다시 등록했더니 「반영 대기」가 풀리지 않아요 | 관리자에게 반영 완료를 부탁해 주세요 |

**연결을 끊으려면** 「외부 서비스 연결」에서 해제하고, 워크벤치의 「더보기 → 연동 토큰」에서 그 토큰도 폐기해 주세요.
해제만 하면 비서 쪽의 값만 지워지고 워크벤치의 토큰은 살아 있어요.
