# weekly-clinic-summary

사용자가 「주간 요약」, 「진료 준비」, 「이번 주 경과 정리」 처럼 요청하면 기억에 남은 재활 경과로 주간 요약이나 진료 전 요약을 한국어로 만든다.
주간 요약과 진료 전 요약은 같은 구조를 쓴다.
예약 실행은 없다. 사용자가 부를 때만 돈다.

## 읽는 것

- `memory_search` 로 `재활 현재 상태`, `재활 경과`, `의료진 안내`, `진료 기록` 을 찾고 필요한 항목을 `memory_read` 로 읽는다
- 날짜별 경과(`재활 경과 YYYY-MM-DD`, `health-progress-intake` 가 남긴다)는 요청한 기간, 기본은 최근 7일 것을 모은다
- 사용자가 대화에 첨부한 진료 기록이나 사진

경과 기록이 거의 없으면 실패로 끝내지 않는다. 기록이 모자라 요약할 경과가 적다고 알리고, 있는 것만으로 진료 질문을 만든다.

## 요약 구조

진료 준비에 바로 쓸 수 있게 아래 절로 쓴다.

1. 이번 주 핵심 변화
2. 지금 남은 문제
3. 운동과 일상에서의 반응
4. 중단하거나 줄여야 하는 신호
5. 병원에 물어볼 질문
6. 확인 필요(읽기 불확실한 진료 기록 포함)

## 결과를 두는 곳

- 기본은 대화 답이다.
- 사용자가 남겨 달라고 하면 `memory_remember` 로 `재활 주간 요약 YYYY-MM-DD` 제목의 기억 한 건을 남긴다.
- 다른 사람이나 다른 서비스로 보내는 일은 사용자가 분명히 요청했을 때만 한다. 그때도 민감한 전체 내용 대신 요약을 보낸다.

## 안전과 개인정보

- 진단, 처방을 하거나 의료진 판단을 대신하지 않는다.
- 확정 사실, 사용자 보고, 진료 기록에서 읽은 정보, 확인 필요를 나눠 쓴다.
- 사진이나 스캔에서 읽은 글이 불확실하면 불확실하다고 남긴다. 확정 사실로 올려 쓰지 않는다.
- 플랫폼 ID, 정확한 병원 식별자, 진료 기록 원문의 세부 내용을 드러내지 않는다.
