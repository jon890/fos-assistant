# 개인정보 처리 안내

fos-assistant 는 사용자가 자기 서버에 직접 설치해 쓰는 오픈소스 개인 비서다.
이 문서는 Gmail 같은 커넥터를 연결할 때 데이터가 어디로 가고 어디에 남는지를 설명한다.
Google OAuth 동의 화면이 이 문서를 개인정보처리방침으로 가리킨다.

## 누가 데이터를 갖는가

- 이 프로젝트의 개발자는 사용자의 데이터를 받거나 보관하지 않는다. 운영하는 중앙 서버가 없다.
- 데이터는 그 사용자가 설치한 서버 안에만 있다. 그 서버의 관리자가 데이터의 관리자다.

## Gmail 커넥터가 다루는 것

- 사용자가 자기 Google 계정으로 만든 OAuth client 와 refresh token 으로 그 계정에만 접근한다.
- 범위는 `https://www.googleapis.com/auth/gmail.modify` 와 `https://www.googleapis.com/auth/gmail.settings.basic` 이다. 메일 읽기, 초안 만들기, 라벨 관리, 보내기, 답장과 자동 분류 필터 관리를 한다. 휴지통으로 보내거나 영구 삭제하는 기능은 없다.
- 쓰기는 사용자가 화면에서 승인해야 실행된다. 라벨 생성·이름·색 변경과 초안은 상시 허락을 줄 수 있지만, 보내기와 답장, 메일의 라벨 변경, 필터 생성·삭제, 기존 메일 일괄 적용은 매번 승인한다.
- 읽은 메일 내용은 그 사용자의 대화에만 쓰이고, 그 서버의 대화 기록에 남는다.
- 대화에 쓰인 내용은 사용자가 그 서버에 설정한 AI 모델 공급자에게 요청의 일부로 전달된다. 어느 공급자를 쓸지는 설치한 사람이 정한다.
- OAuth 비밀값은 그 서버의 Hermes profile 설정 파일에만 두고 데이터베이스와 로그에 원문을 남기지 않는다. 해제하면 그 파일에서도 지워진다.
- Google 에서 받은 데이터를 광고나 다른 목적에 쓰지 않고, 제3자에게 팔거나 넘기지 않는다.

## Google API 서비스 사용자 데이터 정책

Google API 에서 받은 정보의 사용과 전송은 [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy) 와 그 Limited Use 요건을 따른다.

## 연결을 끊고 지우는 법

- 비서의 「연결」 화면에서 Gmail 연결을 해제하면 그 서버에 저장된 OAuth 값이 지워진다.
- Google 계정의 「보안」, 「서드 파티 앱 및 서비스」 에서 앱을 지우면 그 즉시 토큰이 무효가 된다.
- 대화를 지우면 화면에서 사라지지만 메시지 기록은 그 서버의 데이터베이스에 남는다. 완전히 지우려면 그 서버의 관리자가 데이터베이스에서 지운다.
- 승인한 쓰기(보내기, 답장, 초안, 라벨 생성·변경, 필터 생성·삭제, 기존 메일 일괄 적용)는 받는 사람, 제목, 본문, 검색어, 대상 수 같은 인자가 그 서버의 승인 기록에 남는다. 이것도 서버 관리자가 지운다.
