# 무엇을 만드는가

## 목적

**같은 목적을 가진 사람들이 모여 대화로 일을 자동화하고, 그 맥락이 남는 비서다.**

그 모임을 **그룹**이라 부른다.
가족이 한 그룹이고, 친구들이 다른 그룹이다. 무엇으로 묶이는지는 그 사람들이 정한다.

바깥 서비스가 정해 준 비서를 쓰는 것이 아니다.
사람마다 자기 에이전트를 만들고, 그 에이전트가 자기만 볼 수 있는 자리에서 돌고,
여럿을 함께 돌려 하나의 일을 끝낸다.

그래서 네 가지를 지킨다.

- **자기 것이다.** 에이전트의 모델과 도구와 기억을 그 사람이 정한다
- **섞이지 않는다.** 남의 기억과 credential 이 자기 실행에 들어오지 않는다
- **지휘한다.** 하나가 끝나기를 기다리는 것이 아니라 여럿을 나눠 돌리고 합친다.
  무엇을 나눌지는 에이전트가 정하고, 누가 무엇을 볼 수 있는지는 우리가 정한다
- **남는다.** 한 번 알아낸 것을 다음 대화가 다시 묻지 않는다

**사람이 늘어도 같은 방식으로 는다.**
한 사람을 더하는 것이 관리자의 판단 하나로 끝나야 하고,
그 사람 때문에 다른 사람이 느려지거나 남의 것을 보게 되면 안 된다.

에이전트를 실제로 돌리는 것은 Hermes Agent 가 한다.
이 저장소는 그 앞에서 누가 무엇을 쓸 수 있는지 정하고, 화면을 만들고, 쓴 것을 기록한다.
근거는 [ADR-001](adr/ADR-001-hermes를-런타임으로-두고-core를-고치지-않는다.md) 에 있다.

## 범위와 확인 방법

무엇을 하는지와 그것이 됐는지 무엇으로 아는지를 같은 줄에 둔다.

| 무엇을 한다 | 무엇으로 확인한다 |
| --- | --- |
| 사람을 더하는 것이 관리자의 판단 하나로 끝난다 | 관리 화면에서 주소를 더하면 그 사람이 로그인해 바로 대화를 시작한다. 그 사이에 홈서버를 만지지 않는다 |
| 사람마다 에이전트를 만들고 그 에이전트가 모델과 도구를 함께 정한다 | 같은 사람이 에이전트를 골라 대화를 시작하면 그 에이전트의 모델로 돈다 |
| 자기 에이전트의 성격을 자기가 화면에서 쓰고 고친다 | 화면에서 성격을 고치면 그다음 대화부터 그 성격으로 답한다. 그 사이에 홈서버를 만지지 않는다 |
| 실행할 profile 을 요청자의 바인딩에서만 꺼낸다 | 요청 본문에 남의 profile 을 적어도 그것으로 돌지 않는다 |
| 기억을 사람이 승인한 것만 남긴다 | 에이전트가 제안해도 사람이 받아들이기 전에는 저장되지 않는다 |
| 기억을 볼 수 있는 사람에게만 싣는다 | 남의 개인 기억은 실리지도 않고 도구로 읽히지도 않는다 |
| 기억을 층으로 나눠 싣고 나머지는 도구로 읽게 한다 | 항목이 늘어도 대화 한 번의 입력이 그만큼 늘지 않는다 |
| 실행을 시작할 때 기록하고 끝날 때 갱신한다 | 실패하거나 끊긴 실행도 목록에 남는다 |
| 실행 하나가 무엇을 했는지 도구와 자식 실행의 나무로 보인다 | 화면에서 실행 하나를 열면 그 안에서 무엇이 불렸는지 보인다 |
| 구독제로 돌린 실행도 API 가격으로 환산해 보인다 | 실제로 나간 돈과 환산액이 각각 따로 보인다 |
| 비용을 에이전트와 모델과 날짜와 설정으로 나눠 본다 | 무엇을 바꿨더니 얼마가 달라졌는지 화면에서 견줄 수 있다 |
| 여러 에이전트에 일을 나눠 돌리고 결과를 합친다 | 하나의 요청이 자식 실행 여럿을 만들고 그 기록이 한 나무에 남는다 |

각 줄의 근거는 [`adr/INDEX.md`](adr/INDEX.md) 에 있다.
실제로 그렇게 도는지는 [`AGENTS.md`](../AGENTS.md) 의 「확인」 절이 적은 검사가 판정한다.

## 범위 밖

- **Hermes core 를 고치지 않는다.** profile 과 API server 와 plugin hook 만 쓴다.
  근거는 [ADR-001](adr/ADR-001-hermes를-런타임으로-두고-core를-고치지-않는다.md) 에 있다.
- **Hermes 내장 memory 도구를 에이전트에 주지 않는다.**
  기억에 닿는 길을 Control Plane 하나로 둔다.
  근거는 [ADR-003](adr/ADR-003-memory-권한은-주입으로-강제한다.md) 에 있다.
- **사람이 보지 않은 것을 기억에 남기지 않는다.**
  근거는 [ADR-012](adr/ADR-012-memory-는-사람이-승인한-것만-남는다.md) 에 있다.
- **비밀값을 데이터베이스에 넣지 않는다.** profile key 는 홈서버 파일에만 있다.
- **대화를 담는 별도의 작업 영역을 두지 않는다.** 그 자리는 에이전트가 갖는다.
  한 번 만들었다가 지웠다.
  근거는 [ADR-010](adr/ADR-010-작업-영역을-제거하고-에이전트가-그-자리를-갖는다.md) 에 있다.
- **운영 절차를 이 저장소가 갖지 않는다.** 배포와 profile 설정은 `fos-home-infra` 가 갖는다.
- **성공을 수치로 정하지 않는다.** 쓰는 사람이 하나라 표본이 되지 않는다.
  위 표의 「무엇으로 확인한다」 가 그 자리를 대신한다.
- **누구나 가입하는 서비스로 열지 않는다.** 그룹에 사람을 더하는 것은 관리자가 한다.
  모르는 사람이 들어오면 credential 과 비용의 경계를 다시 정해야 한다.

## 아직 정하지 않은 것

- **그룹마다 credential 을 나눌지.** 지금은 한 그룹이 구독 하나를 함께 쓴다.
  근거는 [ADR-002](adr/ADR-002-profile은-나누고-ai-계정은-가족이-함께-쓴다.md) 에 있고,
  그 결정은 가족이라는 신뢰 경계를 전제로 한다.
  그룹이 가족이 아니면 한 사람의 실행이 다른 사람의 한도를 먹는다.
- **비용을 나눌지.** 지금은 누가 얼마를 썼는지 보이기만 하고 나누지 않는다.

아직 만들지 않은 것은 [`code-architecture.md`](code-architecture.md) 의
「아직 만들지 않은 것」 절이 갖는다.
이 문서는 만들 것을 정하고, 그 문서는 지금 어디까지 왔는지를 적는다.
