# 서비스 개념

사용자가 대화에서 서비스의 기능(예약 작업, 기억, 할 일, 외부 서비스 연결, 모델 단계, 에이전트 고르기, 파일 공간)을 평소 말로 부르면 에이전트가 알아듣고 직접 처리하거나 그 화면으로 안내하는 기능이다.

covers: `backend/src/main/java/com/bifos/assistant/chat/artifact/application/ArtifactService.java`

요구와 결정은 스펙 [`service-concepts/spec.md`](service-concepts/spec.md) 가 갖는다.
아직 구현하지 않았다. 지금은 파일 공간 설명만 실행 입력에 있다([`workspace.md`](workspace.md)).
