| REQ7 | 단추로 만든 `READY` 연결과 다시 연결 필요인 연결 | 갱신이 `ok`, `grant_revoked`, `app_rejected`, `unavailable` 을 각각 답하게 하고 「연결 다시 확인」 을 부름 | `ok` 는 갱신 뒤에 확인 도구(`oauth: current`)를 부르고 `READY` 다. 다시 연결 필요였던 연결은 표시가 지워지고 끊김 알림이 읽음이다. `grant_revoked` 는 확인 도구 없이 `CONNECTOR_CREDENTIAL_REJECTED` 이고 다시 연결 필요로 남는다. `app_rejected` 와 `unavailable` 은 확인 도구 없이 `CONNECTOR_UNAVAILABLE` 이고 연결 상태가 그대로다. 붙여 넣은 연결은 갱신을 부르지 않는다 | 가짜 대시보드, H2 | worker | 없음 | PR 전 |
