# 비서가 찾은 사진

사용자가 상품이나 사물, 장소의 이름만 말하며 그림을 부탁하면 비서가 웹에서 그 사진을 찾아 그림의 참고 그림으로 넣는 기능이다.

covers: `backend/src/main/java/com/bifos/assistant/chat/artifact/application/LinkImageService.java`

요구와 결정은 스펙 [`agent-found-image/spec.md`](agent-found-image/spec.md) 가 갖는다.
아직 구현하지 않았다. 지금은 사용자가 대화에 보낸 링크의 사진만 받고 비서가 찾은 주소는 받지 않는다. 그 동작은 [`generated-image.md`](generated-image.md) 가 갖는다.
