# 대화 답장: 메시지와 그림을 집어 「이걸 참고해서」 라고 보낸다

## 목표

사용자가 대화의 메시지나 그림을 길게 눌러 「답장」 이나 「새 대화에서 시작」 을 고르면, 집은 것이 입력창 위에 보이고 사용자가 쓴 글과 함께 비서에게 간다.
비서는 집은 글과 그림을 보고 답하며, 집은 그림은 다시 그릴 때 바탕이나 참고 그림으로 쓴다.
지난 대화에서 만든 그림도 말로 다시 설명하지 않고 집어 새 대화에서 이어 만든다.

지금은 같은 대화 안의 앞 그림만 「앞 그림 고쳐 줘」 처럼 말로 가리킬 수 있다([그림 스펙](../generated-image/spec.md) REQ15, REQ25).
다른 대화의 그림과 사진은 쓰지 못해(그림 스펙 DECISION19) 사용자가 그림을 말로 다시 설명해야 했다. 양말 상품 그림 대화가 그 예다.
대화 화면의 답 아래에는 「답 복사」 와 「답 다시 만들기」 만 있고 메시지를 집는 단추는 없다(`web/src/components/chat/message-actions.tsx`).

사용자가 비교한 개인 비서 서비스(ChatGPT 의 dots 같은 것)에는 이전 대화를 참고하는 기능이 있다. 이 스펙은 그 가운데 사용자가 직접 집어 보내는 쪽을 먼저 만든다(DECISION1, DECISION4).

## 범위

이 스펙은 PR 둘로 구현한다(DECISION16).

| PR | 담는 것 | 시작 조건 | 요구사항 |
| --- | --- | --- | --- |
| PR1 | 같은 대화 안의 답장. 메뉴와 단추(「답장」 과 「복사」 만), 입력창 위 표시, 보낸 메시지의 상자, 비서가 받는 글과 그림, 다시 만들기 | 없음 | REQ1~REQ9, REQ13~REQ15 |
| PR2 | 「새 대화에서 시작」. 단추와 메뉴 항목, 원래 대화의 에이전트로 새 대화 열기, 지난 대화의 그림과 사진 사본, 다른 대화로 가는 상자 | PR1 이 main 에 머지됐다 | REQ10~REQ12 |

범위 밖:

- 비서가 지난 대화를 스스로 찾아 답에 쓰는 「이전 대화 참고」. 요청자의 대화만 찾는 길이 따로 필요해 다음 스펙으로 뺀다(DECISION4)
- 다른 사용자의 메시지와 그림을 집기. 그룹 공개 에이전트와 나눈 대화도 요청자 자기 대화만 집는다(DECISION2)
- 한 메시지에 여럿을 집기(DECISION7)
- 이미 있는 다른 대화로 보내기. 지난 대화의 것은 「새 대화에서 시작」 으로만 가져온다(DECISION13)
- 「파일 공간」 의 「보관한 결과물」 에서 그림을 집기(DECISION13)
- 알림 줄, 승인 카드, 아직 만드는 중인 답을 집기(DECISION14)

## 요구사항과 인수 조건

인수 조건은 가짜 Hermes 와 테스트용 그림 파일로 확인한다.
실제 비서가 집은 그림을 보고 다시 그리는 왕복은 PR 마다 배포 뒤 운영에서 사용자가 확인한다. 절차는 운영 저장소가 갖는다.

| ID | 요구사항 | 관측할 인수 조건 |
| --- | --- | --- |
| REQ1 | 집을 수 있는 것은 내 메시지, 비서 답, 만든 그림, 올린 사진이다. 그림이나 사진을 집으면 그 한 장을, 글을 집으면 그 메시지 전체(그 안의 사진과 그림 포함)를 집는다 | 그림 두 장이 있는 답에서 둘째 그림을 집으면 그 그림만, 답 글을 집으면 답 전체가 입력창 위에 보인다 |
| REQ2 | 컴퓨터 화면에서는 마우스를 올리거나 초점이 들어오면 보이는 단추 줄(지금의 「답 복사」 줄)에 「답장」 과 「새 대화에서 시작」 이 있다. 내 메시지에도 같은 줄이 있다. 그림의 크게 보기 화면에도 두 단추가 있다 | 넓은 화면에서 내 메시지와 비서 답에 마우스를 올리면 두 단추가 보이고, 그림을 눌러 연 크게 보기 화면에도 두 단추가 있다. 키보드로 초점을 옮겨도 보인다 |
| REQ3 | 휴대폰 폭에서는 메시지나 그림을 길게 누르면 「답장」, 「새 대화에서 시작」, 「복사」 가 있는 메뉴가 뜬다. 브라우저의 글 선택과 그림 저장 메뉴는 뜨지 않는다. 「복사」 는 메시지 글 전체를 복사한다 | 휴대폰 폭에서 메시지와 그림을 길게 누르면 세 항목이 있는 메뉴가 열리고 브라우저 메뉴는 뜨지 않는다. 메뉴 밖을 누르면 닫힌다 |
| REQ4 | 「답장」 을 고르면 입력창 위에 집은 것이 작게 보인다. 글은 앞 두 줄, 그림과 사진은 작은 그림이고, 그림이 든 메시지는 글 두 줄과 작은 그림을 함께 보인다. 표시 옆의 닫기 단추로 뺄 수 있다. 새로 집으면 앞에 집은 것이 바뀐다 | 답을 집으면 입력창 위에 답의 앞 두 줄이 보이고, 다른 그림을 집으면 그 그림으로 바뀐다. 닫기를 누르면 사라진다 |
| REQ5 | 집은 것과 사진 올리기는 한 메시지에 함께 쓴다. 글이 없으면 집은 것이나 사진이 있어도 보내지 않는다(지금의 보내기 규칙과 같다). 집은 것은 보내기 전까지 그 대화 화면에만 남고, 다른 대화로 가거나 새로 고치면 쓰던 글처럼 사라진다 | 그림을 집고 사진 한 장을 올린 뒤 글을 쓰면 보내진다. 글 없이 집은 것만 있으면 보내기 단추가 꺼져 있다 |
| REQ6 | 보낸 내 메시지 위에 집은 것이 작은 상자(REQ4 와 같은 모양)로 남는다. 상자를 누르면 같은 대화면 원래 메시지로 스크롤하고 잠시 표시한다. 대화를 다시 열어도 같다 | 답장을 보낸 뒤 대화를 다시 열어도 내 메시지 위에 상자가 있고, 누르면 원래 답으로 스크롤된다 |
| REQ7 | 비서는 집은 것을 그 메시지에서 사용자가 가리킨 것으로 받는다. 집은 글은 누가 쓴 것인지(사용자, 비서)와 함께 전문을 받는다. 집은 그림과 사진은 이번 메시지에 올린 사진처럼 비서가 보되 새 사진 순번을 받지 않고, 비서는 원래의 순번이나 제목으로 부른다 | 가짜 Hermes 가 받은 실행 입력에 집은 메시지의 쓴 사람과 전문이 사용자의 글과 구분돼 있고, 집은 그림이 사진으로 들어 있다 |
| REQ8 | 집은 그림과 사진은 그 메시지의 그림 만들기에서 바탕이나 참고 그림으로 쓸 수 있다. 사용자가 「이걸 참고해서」 라고만 해도 비서가 집은 그림을 가리킨다. 바탕으로 쓸지 참고로 쓸지는 사용자의 글을 따른다. 집은 메시지에 그림이 여럿인데 어느 그림인지 글에 없으면 비서가 되묻는다 | 그림을 집고 「이 그림을 수채화로 바꿔 줘」 라고 보내면 이미지 도구가 그 그림을 바탕으로 받고, 답에 새 그림이 그림 스펙 REQ1 과 같이 보인다 |
| REQ9 | 답장을 보내기 전, 입력창 위에 있는 동안 원래 메시지가 지워졌거나 집은 그림과 사진의 보관 기간이 지났으면 보내지 않고 「원래 메시지를 찾을 수 없어요. 다시 집어 주세요」 를 보인다. 쓴 글은 입력창에 남는다 | 집은 뒤 그 그림 파일을 지우고 보내면 메시지가 저장되지 않고 안내가 보이며, 입력창의 글이 그대로다 |
| REQ10 | 「새 대화에서 시작」 을 고르면 원래 대화의 에이전트로 새 대화 화면을 열고 집은 것을 입력창 위에 둔다. 사용자가 글을 써서 보낸다. 보내기 전에 에이전트를 바꿀 수 있다. 원래 대화의 에이전트를 지금 쓸 수 없으면 기본 비서로 열고 「원래 에이전트를 쓸 수 없어 기본 비서로 열었어요」 를 보인다 | 지난 대화의 그림에서 「새 대화에서 시작」 을 누르면 새 대화 화면이 그 대화의 에이전트로 열리고 입력창 위에 그 그림이 있다. 보내면 새 대화가 생긴다 |
| REQ11 | 지난 대화의 그림과 사진을 새 대화로 보내면 새 대화의 사진으로 사본을 만든다. 사본은 올린 사진과 같은 보관 기간(30일)과 크기 상한을 따르고, 원래 대화를 지우거나 원래 그림의 보관 기간이 지나도 새 대화에서 보이고 바탕으로 쓸 수 있다. 크기 상한을 넘으면 보내지 않고 까닭을 보인다 | 지난 대화의 그림으로 새 대화를 시작한 뒤 원래 대화를 지워도, 새 대화에서 그 그림이 보이고 「이 그림을 바탕으로 고쳐 줘」 에 이미지 도구가 그 사본을 받는다 |
| REQ12 | 다른 대화에서 가져온 것의 상자를 누르면 원래 대화를 열고 그 메시지로 스크롤한다 | 새 대화의 상자를 누르면 원래 대화가 열리고 그 메시지가 보인다 |
| REQ13 | 보낸 뒤 원래 메시지가 지워져도 보낸 상자는 그대로 남는다(집은 글의 앞 두 줄, 그림은 사본이 있으면 작은 그림). 상자를 누르면 「원래 메시지를 찾을 수 없어요」 만 보인다. 사본이 없는 같은 대화 그림의 보관 기간이 지나면 상자의 작은 그림 자리에 보관 기간이 지났다는 표시가 보인다 | 답장을 보낸 뒤 원래 대화를 지우면 상자의 글이 그대로이고, 누르면 안내만 보인다 |
| REQ14 | 집을 수 있는 것은 요청자 자기 대화의 것뿐이다. 다른 사용자의 메시지, 그림, 사진을 가리키면 Control Plane 이 거절하고 메시지를 저장하지 않는다 | 다른 사용자의 메시지 번호를 넣어 보내는 요청은 없는 메시지와 같은 응답을 받고 저장되지 않는다 |
| REQ15 | 답장의 답을 「답 다시 만들기」 하면 집은 것을 다시 넘긴다. 원래가 지워졌으면 보낸 상자의 글과 사본(있으면)만 넘기고, 사본 없는 같은 대화 그림의 기간이 지났으면 그림 없이 다시 만든다 | 답장의 답을 다시 만들면 가짜 Hermes 가 받은 입력에 집은 글과 그림이 다시 있다. 원래 메시지를 지운 뒤 다시 만들어도 실패하지 않고 상자의 글이 입력에 있다 |
