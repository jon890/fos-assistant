# 실행 기록에 모델 호출마다의 시간과 토큰, 도구마다의 시간과 실패 원인을 남긴다

## 목표

관리자가 실행 하나를 열면 그 실행이 모델을 언제 몇 번 불렀고 한 번에 얼마나 걸렸는지, 도구가 각각 얼마나 걸렸고 실패한 도구가 무엇이었는지 본다.
그래서 「어느 호출이 왜 느렸는지」 를 외부 관찰 서비스 없이 우리 실행 기록만으로 안다(사용자 결정 2026-11-24: Langfuse 같은 외부 서비스 대신 우리 실행 기록에 더 남긴다).

지금은 아래와 같다(2026-11-24).

- 실행 줄에는 실행 한 번의 토큰 합계와 네 시각만 남는다([`backend/docs/data-schema.md`](../../../backend/docs/data-schema.md) 의 「agent_execution」). 합계는 Hermes 가 끝난 실행에만 주므로, 시간 제한에 걸려 끝난 실행은 토큰이 비어 있다
- 모델을 몇 번 불렀는지, 한 번에 얼마나 걸렸는지는 어디에도 없다. Runs API 의 `usage` 는 합계뿐이고 사건 스트림에도 모델 호출 사건이 없다([`hermes-contract.md`](../../../hermes/docs/hermes-contract.md) 의 「plugin hook」, 「실행 이벤트가 실제로 오는 형태」)
- 실행 상세의 도구 줄이 모두 0ms 로 보인다. Hermes v0.23.2 의 실행 대기열 경로는 `tool.completed` 의 `duration` 을 늘 0 으로 보내고(같은 문서), 화면은 값이 없을 때도 0 으로 그린다(`web/src/components/execution/execution-event-row.tsx`)
- 실패한 도구는 실패했다는 것만 남는다. v0.23.2 의 완료 사건에는 결과 `preview` 가 없어 오류 내용이 오지 않는다(상류 `gateway/platforms/api_server_runs.py`)
- 플러그인 도구를 부른 트리의 뒤쪽 도구는 「[도구 내용 가림: 0자]」 로 보인다. 플러그인 호출 뒤에는 내용의 길이만 남기는 규칙(#319)이 빈 내용에도 그 문구를 붙인다(`ToolDetailRedactor`)
- 실제 사례: 커리어 브리핑 실행 1981 은 모델 왕복 약 21번(한 번에 10~26초)과 collect 도구 78초로 5분을 넘겼다. 호출마다의 시간과 토큰이 없어 무엇을 망설였는지 보지 못했다

Hermes 는 core 를 고치지 않고도 이 값을 plugin hook 으로 준다(v0.23.2 소스로 확인, 2026-11-24).

| hook | 주는 것 |
| --- | --- |
| `post_api_request` | 모델 호출 하나의 시작·끝 시각, 첫 조각 시각, 실제 모델과 provider, 입력·출력·캐시 읽기·캐시 쓰기·reasoning 토큰, 끝난 이유, 그 응답이 부른 도구 수 |
| `api_request_error` | 실패한 모델 호출의 시각, 상태 코드, 오류 종류, 다시 시도한 횟수 |
| `post_auxiliary_call` | 문맥 압축, 제목 만들기, 사진 판독 같은 보조 모델 호출. 모양은 `post_api_request` 와 같고 `aux_task` 가 붙는다 |
| `post_tool_call` | 도구 하나의 걸린 시간(ms), 성공·실패, 오류 종류와 오류 글 |

hook 은 요청과 응답의 본문(대화 내용, 시스템 프롬프트)도 함께 받는다. 이 스펙은 본문을 Control Plane 으로 보내지 않는다(REQ6).

## 범위

<!-- 결정 라운드에서 닫는다. 아래는 권장안이다. -->

**하지 않는 것.**

- 외부 관찰 서비스(Langfuse 등)로 보내는 것(사용자 결정 2026-11-24)
- 모델에 보낸 글과 받은 글, 시스템 프롬프트를 남기는 것
- 관리자가 남의 실행 상세를 여는 것. 지금처럼 본인 실행만 연다([`admin-area/spec.md`](../admin-area/spec.md) DECISION10)
- Hermes core 를 고치는 것

## 도메인 규칙 변경

도메인 규칙 변경 없음: 실행 기록 보존(rule-49), 도구 내용 가림(ADR-047), 관리자 전용 값(ADR-063)을 그대로 따른다.
