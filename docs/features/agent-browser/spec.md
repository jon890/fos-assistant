# 에이전트가 「내 브라우저」 를 스스로 조작한다

사용자 확인 전 초안. 결정 표의 ‘작성자(위임)’은 최종 확인 대상이다.

## 목표

에이전트가 플러그인이 없는 사이트에서도 「내 브라우저」 의 탭을 정리하고, 로그인해야 보이는 화면을 읽고, 신청·예약 양식과 글 초안을 채운다.
결제, 비밀번호와 인증 입력, 게시·전송·제출의 마지막 누르기, 계정 설정 변경과 삭제는 에이전트가 하지 않고 그 직전에 멈춰 사람에게 넘긴다.

지금 에이전트가 브라우저에 닿는 길은 플러그인(네이버 쇼핑, 코레일 KTX, 네이버 블로그)의 정해진 코드뿐이다([browser-cowork 스펙](../browser-cowork/spec.md) 의 목표).
[ADR-20261007 / user-browser](../../adr/ADR-20261007-user-browser.md) 는 모델이 로그인된 세션으로 아무 사이트나 다니는 길을 「나중에 따로 정한다」 로 미뤘고, 이 스펙이 그 결정을 내린다.

## 범위

사용자가 켜면 기본 비서와 전문 에이전트가 요청자 자신의 브라우저를 쓴다. 현재 화면의 텍스트와 필요한 화면 사진 읽기, 탭 목록·열기·닫기, 화면 요소 누르기와 글자 넣기를 제공한다. 탭 순서 바꾸기, 파일 올리기·내려받기, 임의 스크립트나 브라우저 명령 실행은 범위 밖이다.

## 요구사항과 인수 조건

| ID | 요구사항 | 관측할 인수 조건 |
| --- | --- | --- |
| REQ1 | 사용자가 자기 브라우저를 열어 준 동안만 접근한다 | 처음에는 탭 목록도 볼 수 없다. 사용자가 켠 뒤에도 다른 사용자의 탭은 볼 수 없다. 사용자나 관리자가 끄면 다음 호출과 대기 중인 승인 실행이 거절된다. |
| REQ2 | 허용한 탭의 목록과 현재 화면을 읽는다 | 페이지를 바꾸지 않고 로그인한 사이트의 정보를 읽어 답한다. 열린 탭이 없으면 빈 목록을 돌려준다. 접근을 막은 탭, 다른 실행이나 넘기기 카드가 쥔 탭의 제목·주소·내용은 모델에 전달하지 않는다. |
| REQ3 | 사용자가 같은 화면에서 할 일을 보고 승인한다 | 승인 카드에 대상 탭과 조작을 보인다. 승인 전이나 거절 뒤에는 조작하지 않는다. 양식의 여러 칸은 한 번에 채울 수 있다. 탭이나 화면이 바뀌거나 사용자가 회수하면 남은 조작을 멈추고 이전 승인을 다시 쓸 수 없다. |
| REQ4 | 사람 탭을 조작할 때 작성 중인 내용을 보호한다 | 사람 탭을 닫거나 다른 페이지로 이동하거나 입력값을 덮어쓰는 경우, 승인 카드가 대상과 잃을 수 있는 작업을 알린다. 사이트가 이탈 여부를 물으면 사람이 결정한다. 조작 중 사람은 보기 전용이며 「직접 할게요」를 누르면 즉시 조작권을 되찾는다. |
| REQ5 | 사람만 할 수 있는 동작 직전에 넘긴다 | 예약 신청서와 게시글은 초안까지 채운다. 로그인·인증 입력, 결제·주문 확정, 전송·제출, 계정 변경·삭제를 만나거나 버튼의 효과가 불분명하면 승인받은 화면에서도 멈춘다. 사람이 대화의 넘기기 카드로 해당 탭을 열 수 있다. |
| REQ6 | 사용자가 자리를 비운 동안에도 실행별 권한을 지킨다 | 예약 작업은 화면 승인이 필요하면 할 일로 남긴다. 읽기 전용 살펴보기는 탭을 닫아 달라는 상황에서도 조작하지 않고 할 일을 제안한다. 쓰기를 허용한 살펴보기에서도 승인 없이 탭을 닫지 않는다. |
| REQ7 | 사이트 차단과 플러그인별 승인을 지킨다 | 기본 목록이나 관리자 추가 목록에 든 사이트는 이동 전과 이동 결과 모두에서 접근을 막는다. 기존 플러그인이 처리하는 구매·예매·게시 요청은 그 플러그인의 승인과 넘기기 흐름을 따른다. |
| REQ8 | 성공과 실패를 나중에 확인할 수 있다 | 도구 줄과 실행 기록에는 사이트 이름, 동작 종류, 시각, 결과와 실패 이유가 남는다. 실패 이유를 포함해 전체 주소, 화면 본문, 입력값, 화면 사진이 기록에 복사되지 않는다. |

## 도메인 규칙 변경

도메인 규칙 변경 없음: 기존 탭 소유권과 사람에게 넘기는 규칙을 재사용한다.

[내 브라우저](../user-browser.md)의 로그인 세션 접근 범위에 사용자가 켠 내장 도구를 추가한다. 탭 소유권은 [탭 잠금과 회수](../browser-cowork/spec.md), 사람에게 넘긴 뒤의 흐름은 [화면 넘기기 결정](../../adr/ADR-20261111-connector-handoff.md)을 따른다.
