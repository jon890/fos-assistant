## ADR-010: 작업 영역을 제거하고 에이전트가 그 자리를 갖는다

- **status**: `accepted`
- **결정**: 작업 영역(workspace)을 제거한다.
  표와 패키지와 API 와 화면을 지우고 `conversation` 과 `agent_execution` 의 `workspace_id` 칸도 내린다.
  `fos-agents` 를 읽기 전용으로 마운트해 `AGENTS.md` 를 싣던 경로도 함께 지운다.
  도메인 지식과 운영 규칙은 에이전트가 가리키는 Hermes profile 이 갖는다.

### 맥락

[ADR-006](ADR-006-작업-영역은-읽기-전용-의존이고-공개-범위는-기본값이-없다.md) 이
작업 영역을 도입했다. 공부, 집안일, 구직처럼 영역마다 다른 규칙을
`fos-agents` 의 `AGENTS.md` 로 싣기 위한 것이었다.

그 뒤 [ADR-007](ADR-007-에이전트가-모델과-도구를-함께-정한다.md) 이
에이전트가 모델과 도구를 함께 정하도록 했다.
에이전트가 가리키는 Hermes profile 이 스킬과 `SOUL.md` 와 도구 범위를 모두 들고 있어,
"어떤 일을 어떤 규칙으로 하는가" 가 이미 에이전트에 붙었다.

운영 기록이 그것을 보여준다.

| 무엇 | 수 |
| --- | --- |
| 등록된 작업 영역 | 0 |
| `workspace_id` 가 채워진 대화 | 0 (전체 11건) |
| `workspace_id` 가 채워진 실행 | 0 (전체 15건) |

작업 영역은 만들어진 뒤 한 번도 쓰이지 않았다.
같은 기간에 `career` 에이전트는 `career-os` 스킬 여섯 개를 붙여 실제로 돌았다.

앞으로 만들 것은 여러 에이전트를 잇는 실행 구조다.
`Chief` 와 `Orchestrator` 와 `Specialist` 는 모두 에이전트이고 작업 영역이 아니다.
격리 단위는 대화이고 성격 단위는 에이전트인데,
작업 영역은 그 사이에서 아무것도 맡지 않는 세 번째 단위로 남는다.

### 대체된 부분

[ADR-006](ADR-006-작업-영역은-읽기-전용-의존이고-공개-범위는-기본값이-없다.md) 의 결정 전체를
이 ADR 이 대체한다. 그 문서는 이력으로만 읽는다.

다만 ADR-006 이 담은 판단 하나는 여기서도 유효하다.
**여러 사람이 보는 것을 등록할 때 공개 범위에 기본값을 두지 않는다.**
`agent` 의 `visibility` 가 그 규칙을 그대로 쓰고 있고, 앞으로 만들 Memory 도 같게 한다.

### 대안 기각

- **칸만 남기고 코드를 지운다.**
  쓰이지 않는 칸이 스키마에 남아, 다음에 읽는 사람이 그것이 무엇인지 다시 확인해야 한다.
  모든 행이 `NULL` 이라 지금 지우면 잃는 기록이 없다.
- **`AGENTS.md` 를 싣는 기능만 에이전트로 옮긴다.**
  `agent` 표에 `source_path` 를 더하고 마운트를 유지하는 길이다.
  Hermes profile 이 이미 같은 일을 스킬과 `SOUL.md` 로 하고 있어 두 경로가 겹친다.
  실을 것이 생기면 그 profile 에 넣는 것이 한 곳에서 끝난다.
- **그대로 두고 나중에 쓴다.**
  Memory 와 실행 구조를 이 위에 얹으면, 등록된 행이 없는 단위에 의존하게 된다.

### 결과

얻는 것

- 실행 하나를 설명하는 축이 사용자, 대화, 에이전트 셋으로 줄어든다.
- Memory 의 범위를 정할 때 쓰이지 않는 단위를 고려하지 않아도 된다.
- `fos-assistant` 가 `fos-agents` 의 디렉터리 구조를 알지 않아도 된다.
  두 저장소 사이에 남는 것은 없다.

감당할 것

- 영역마다 다른 규칙을 싣고 싶어지면 에이전트를 더 만들어야 한다.
  profile 하나가 더 필요하고 그 profile 의 key 도 홈서버에 더해야 한다.
- 비용을 영역별로 나눠 보는 축이 사라진다.
  사용자, 에이전트, provider, 모델, 날짜와 실행의 부모·뿌리 관계로 본다.
- 마이그레이션이 되돌리기 어렵다. 칸을 내리면 그 칸의 값은 돌아오지 않는다.
  지금은 모든 행이 `NULL` 이라 잃을 값이 없다.
