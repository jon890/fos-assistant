## ADR-004: 토큰은 지금 적고 비용은 나중에 계산한다

- Status: Accepted
- Date: 2026-09-17

### 맥락

지금 연결하는 credential 은 구독형이다.
구독형은 실행 한 번의 금액을 계산할 근거가 없다.
나중에 OpenAI API, Anthropic API, OpenRouter 를 붙이면 그때는 토큰으로 금액을 계산할 수 있다.

가격은 바뀐다.
지난 실행의 금액이 오늘 가격표로 다시 계산되면 기록이 흔들린다.

### 결정

`agent_execution` 한 줄에 실행 하나를 적는다.
사용자, 대화, profile, provider, 모델, 상태, 오류 코드,
입력 토큰, cached 입력 토큰, 출력 토큰, 합계 토큰, 소요 시간을 남긴다.

금액 칸은 처음부터 두되 비워 둔다.

| 칸 | 뜻 |
| --- | --- |
| `cost_mode` | `SUBSCRIPTION` 이면 금액을 계산하지 않고 `API` 면 계산할 수 있다 |
| `estimated_cost_micros` | 통화 단위의 100만분의 1 단위 정수 |
| `cost_currency` | 통화 |
| `pricing_version` | 계산에 쓴 가격표 |

금액을 정수로 두는 이유는 데이터베이스에서 반올림이 일어나지 않게 하기 위해서다.
`pricing_version` 을 남기는 이유는 가격이 바뀌어도 지난 기록을 다시 계산하지 않기 위해서다.

실패한 실행도 남긴다.
실패도 토큰을 쓰고, 무엇이 실패했는지는 사용량 화면에서 보여야 한다.

### 거절한 대안

- 금액 칸을 나중에 추가하는 방식은 그 시점에 지난 기록을 되살릴 수 없으므로 쓰지 않는다.
- 금액을 부동소수로 두는 방식은 합계에서 오차가 쌓이므로 쓰지 않는다.
- 조회할 때마다 가격표로 계산하는 방식은 가격이 바뀌면 지난 달 합계가 달라지므로 쓰지 않는다.

### 결과

구독형만 쓰는 지금도 토큰과 소요 시간은 쌓인다.
API 형 credential 을 붙이는 날 가격표만 더하면 지난 기록부터 계산할 수 있다.

Runs API 의 `usage` 는 실행 하나의 합계만 준다.
한 실행 안에서 모델이 바뀌면 그 구분은 지금 기록에 남지 않는다.
필요해지면 `post_llm_call` plugin 으로 호출 단위 기록을 더한다.
