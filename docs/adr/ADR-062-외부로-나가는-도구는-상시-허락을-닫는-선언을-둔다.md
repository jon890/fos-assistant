## ADR-062: 외부로 나가는 도구는 상시 허락을 닫는 선언을 둔다

- **status**: `accepted`
- Date: 2026-10-02
- [ADR-050](ADR-050-커넥터-쓰기는-control-plane-이-승인-줄을-저장하고-승인한-인자로-한-번만-실행한다.md) 의 「상시 허락은 `approval: required` 인 도구에만 만든다」 에 조건을 더한다. 도구가 선언으로 상시 허락을 닫을 수 있다.

### 결정

**`connector.json` 의 도구 선언에 `grant` 를 둔다. `"grant": false` 인 도구는 호출마다 승인을 받고 상시 허락을 만들 수 없다.**

| 항목 | 정한 것 |
| --- | --- |
| 선언 | `tools.<이름>.grant` 는 boolean 이다. 없으면 참이다 |
| 쓸 수 있는 곳 | `approval` 이 `required` 인 도구에만 선언한다. `none` 이나 `always` 인 도구에 선언하면 그 커넥터를 카탈로그에 내지 않는다 |
| 판정 | `grant` 가 거짓인 도구는 유효한 상시 허락이 남아 있어도 승인 필요로 판정한다 |
| 카탈로그 | 대시보드 plugin 이 기본값을 채운 `grant` 를 도구마다 낸다. Control Plane 은 그 값을 선언으로 읽고, 승인 줄에는 따로 저장하지 않는다. 승인 줄을 읽을 때와 승인할 때의 카탈로그로 본다 |
| 승인 | 그 도구의 승인 요청에 기간(`grant`)을 실어 보내면 `VALIDATION_FAILED` 다. 승인 카드는 「승인하고 묻지 않기」 를 그리지 않는다 |
| 모델에게 보이는가 | 보인다. `approval: always` 와 달리 설치가 `tools.exclude` 에 넣지 않는다 |
| 권고 | 데이터를 계정 밖의 사람에게 보내는 도구(메일 보내기, 게시, 공유)는 `grant: false` 로 선언한다 |

### 맥락

커넥터 에이전트는 외부에서 온 글을 읽는다. 그 글이 모델을 속일 수 있다는 전제로 쓰기에 승인을 건다(ADR-049).
그런데 `required` 도구에는 승인 카드에서 30일까지의 상시 허락을 줄 수 있다.
메일을 보내는 도구에 상시 허락이 있으면, 받은 메일의 숨은 지시가 모델을 속였을 때 사람이 보지 않은 메일이 나간다.
읽은 내용을 밖으로 내보내는 길이 열린다.

`approval: always` 는 이 용도로 쓸 수 없다. 설치가 그 도구를 모델에게서 빼기 때문이다.
`always` 는 지금 `DESTRUCTIVE` 와 `FINANCIAL` 의 하한이고, 그 위험도는 호출을 늘 거절한다.

### 대안 기각

- **`always` 를 모델에게 보이게 바꾼다**: `always` 로 선언된 기존 도구가 배포한 순간 모델에게 나타난다. 웹도 `ALWAYS` 를 「아직 쓸 수 없어요」 로 보인다. 이미 있는 뜻을 바꾸는 것보다 새 칸을 더하는 쪽이 옛 선언을 건드리지 않는다.
- **문서로만 경고한다**: 승인 카드에 단추가 있으면 누른다. 승인 요청이 많을수록 그렇다.
- **위험도를 하나 더 만든다**: 위험도는 무엇을 하는 도구인지이고, 상시 허락은 승인을 어떻게 받는지다. 한 축에 섞으면 하한 표가 복잡해진다.
- **Control Plane 이 도구 이름으로 판단한다**: Control Plane 은 서비스와 도구의 뜻을 모른다(ADR-043).

### 결과

- 얻는 것: 밖으로 나가는 호출은 그때마다 사람이 받는 사람과 내용을 본다. 선언 한 칸이라 다른 커넥터도 같은 방법으로 닫는다.
- 감당할 것:
  - 그 도구를 자주 쓰는 사용자는 매번 승인한다.
  - 어느 도구가 밖으로 나가는지는 만든 사람이 판단한다. 공통 검사는 이 칸의 형식만 본다. 리뷰가 분류를 본다.
  - 옛 대시보드 plugin 은 `grant` 를 모르는 칸으로 읽어 그 커넥터를 카탈로그에서 뺀다. plugin 을 먼저 올린다([ADR-041](ADR-041-hermes-에-설치하는-plugin-과-profile-틀은-이-저장소가-소유한다.md)).
  - `grant` 를 참에서 거짓으로 바꾼 커넥터의 남은 상시 허락은 지우지 않는다. 판정이 보지 않으므로 효력이 없고 기간이 지나면 사라진다.
