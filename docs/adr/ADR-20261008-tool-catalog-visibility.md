## ADR-20261008: 관리자는 그룹의 도구 선택 목록을 정하고 숨김은 활성 상태를 바꾸지 않는다

- **status**: `accepted`
- Date: 2026-10-08

### 결정

그룹이 숨긴 toolset 이름만 Control Plane의 `toolset_hidden` 표에 둔다.
기본값은 모두 보임이다. 운영에서 쓸 이름은 코드나 마이그레이션에 넣지 않고 관리자가 정한다.
숨김은 에이전트 도구 선택 목록에만 적용하며 Hermes의 활성 도구 목록은 그대로 둔다.
기존 OWNER/ADMIN 등급과 비공개 에이전트 조건도 유지한다.

일반 도구 GET과 PUT 응답에서는 숨긴 toolset을 제외한다. ADMIN도 일반 경로에서는 같은 목록을 받는다.
일반 PUT에 숨긴 이름을 명시하면 403으로 거절한다. 다른 도구를 저장할 때는 현재 활성 목록에서
숨긴 이름을 다시 더한 뒤 등급을 검증하고 Hermes에 쓴다. 주인이 받지 않은 관리자 도구와
올린 스킬 때문에 켜 둔 `skills`가 전체 목록 저장에서 꺼지는 것을 막는다.

관리자 경로의 에이전트 도구 응답은 숨긴 항목도 `hidden: true`로 돌려준다.
연결 화면의 안내에는 별도 `shellOrFileEnabled`와 `skillsEnabled`를 사용한다.
이 두 값은 숨김과 무관한 실제 활성 여부이며 숨긴 도구 이름을 일반 응답에 싣지 않는다.
셸 도구가 숨겨져도 연결의 위험 안내를 유지하고, 숨긴 스킬을 꺼진 것으로 안내하지 않는다.
관리자는 그 화면에서 기존 도구를 끌 수 있다. 관리자 경로에서는 숨긴 도구를 켜는 것도 기존 등급 규칙으로 허용한다.
숨김을 실행 권한 취소로 사용하지 않는다.

`/admin/tools`의 「화면에 보일 도구」에서 보임과 숨김을 바로 저장한다.
각 줄에 「켜진 에이전트 N개」와 관리 화면 링크를 보여, 숨긴 도구를 쓰는 에이전트를 찾아 끌 수 있게 한다.
설치 하나가 그룹 하나를 갖는 현재 구조에서 지우지 않은 일반 에이전트 전체를 센다.
꺼진 에이전트도 설정이 남아 있으므로 포함하며 커넥터 관리 에이전트는 제외한다.
어느 profile의 활성 목록을 읽지 못하면 수를 0으로 추정하지 않고 전체 조회를 실패시킨다.
Hermes 카탈로그에서 사라진 숨김 이름은 관리자 목록에 남겨 숨김을 해제할 수 있게 한다.

### 배경과 대안

Hermes 카탈로그에는 설치에서 사용하지 않는 도구도 있다. 이름을 코드에서 빼면 설치마다
별도 배포가 필요하고 새 설치의 기본 동작도 바뀐다. 그룹별 설정으로 선택 목록을 정한다.

숨길 때 활성 도구를 자동으로 끄면 기존 에이전트의 동작이 바뀌고 여러 profile에 걸친 저장 실패를
복구해야 한다. 숨김과 활성 상태를 별도로 다뤄 관리자가 영향을 보고 도구를 끄게 한다.
등급을 바꿔 숨김을 구현하는 대안은 변경 권한과 화면 노출을 섞으므로 기각한다.

### 검증

그룹별 저장과 기본값, 일반 경로의 제외와 명시 요청 거절, 전체 목록 저장에서 활성 상태 보존,
숨긴 `skills` 보존, 관리자 경로에서 끄기, 활성 에이전트 집계와 실패 전달을 테스트한다.
브라우저 검사에서 숨김 저장과 다시 열기, 일반 화면의 제외, 관리자 숨김 표시와 끄기,
일반 사용자의 관리 경로 접근 거절, 조회 재시도와 저장 실패를 확인한다.
