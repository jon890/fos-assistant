## ADR-20261119 / tier-model-names: 모델 단계를 고르는 곳에는 모든 사용자에게 그 단계의 모델과 강도를 보이고, 고르는 모양은 세로 목록으로 한다

- **status**: `accepted`
- Date: 2026-11-19
- **decision-type**: `domain-policy`
- **areas**: `security`
- **현재 규칙의 원본**: 스펙 [`docs/features/model-usage/spec.md`](../features/model-usage/spec.md)(사용자 확인 2026-11-19), 빼는 값의 표는 [`docs/features/chat.md`](../features/chat.md) 의 「역할에 따라 응답에서 빼는 값」, 화면은 [`docs/features/model-usage.md`](../features/model-usage.md) 의 「모델을 고를 때」
- [ADR-063](ADR-063-관리자-전용-표시와-동작은-관리자-영역에만-두고-일반-경로의-응답은-서버가-역할에-따라-줄인다.md) 가운데 「단계 목록의 모델과 강도를 `MEMBER` 역할에게 뺀다」 를 대체한다. 나머지는 그대로다.
- [ADR-20261101 / model-setting](ADR-20261101-model-setting.md) 가운데 「고르는 모양은 슬라이더」 를 대체한다. 단계의 이름과 차례, 그룹 설정 하나, 개별 모델 고르기를 없앤 것은 그대로다.

### 결정

**단계를 고르는 곳(대화 입력창의 모델 선택, 예약 작업 화면의 모델 단계)에는 역할과 상관없이 단계마다 모델 이름과 강도를 보인다. provider 는 보이지 않는다. 입력창의 고르는 모양은 가로 슬라이더 대신 세로 목록이다.**

| 항목 | 정한 것 |
| --- | --- |
| 보이는 값 | 모델 이름과 강도. 저장된 값을 그대로 보인다 |
| 보이지 않는 값 | provider. `MEMBER` 역할에게는 응답에서도 뺀다 |
| 그대로 두는 곳 | 실행 기록, 사용량, 대화 안 작업 과정의 모델과 토큰, 금액은 관리자 영역에만 둔다 |
| 고르는 모양 | 줄마다 단계 이름과 그 아래 모델과 강도, 고른 줄의 체크 표시. 닫힌 단추는 단계 이름만 보인다 |

### 맥락

사용자가 2026-11-19 에 「능력을 선택할 때 모델의 이름도 같이 나왔으면 좋겠다」 고 요청했고, 그룹의 모든 사용자에게 강도까지 보이기로 정했다.
새 모델이 나오면 관리자가 단계의 모델을 바꾼다. 단계 이름만 보여서는 사용자가 자기 대화가 새 모델로 도는지 알 수 없었다.
가로 슬라이더는 휴대폰 폭에서 한 칸이 약 70px 라 모델 이름이 들어가지 않는다.

### 대안 기각

- **관리자에게만 입력창에 모델을 보인다**: 일반 화면에 `ADMIN` 만 보는 표시가 다시 생긴다. ADR-063 이 없앤 것이다. 사용자도 모든 사용자에게 보이기를 골랐다.
- **슬라이더를 두고 고른 칸의 모델만 한 줄로 보인다**: 다른 칸의 모델은 그 칸으로 옮겨야 보이고, 옮기면 바로 저장된다. 고르기 전에 비교할 수 없다.
- **슬라이더 아래에 단계별 모델 목록을 덧붙인다**: 같은 단계 이름이 두 번 나오고 팝오버가 길어진다.
- **실행 기록까지 모델을 보인다**: 요청은 고를 때의 표시다. 실행 기록의 모델은 토큰, 금액과 같은 줄에 있어 응답에서 빼던 값을 여러 화면에서 다시 넣어야 한다.
- **provider 도 함께 보인다**: 화면이 그리지 않는 값이다. 그리지 않는 값은 응답에서도 빼는 ADR-063 의 원칙을 지킨다.

### 결과

- 얻는 것: 사용자가 단계를 고르기 전에 단계마다 어떤 모델과 강도로 도는지 비교한다. 관리자가 단계의 모델을 바꾸면 모든 사용자의 목록에 바로 보인다.
- 감당할 것:
  - `MEMBER` 역할 사용자가 그룹이 쓰는 모델 이름과 강도를 안다. 금액과 토큰은 여전히 모른다.
  - ChatGPT 의 Thinking 슬라이더와 모양이 달라진다. 단계의 이름과 차례는 ChatGPT 와 같다.
  - 보이는 강도는 관리자가 정한 값이다. Hermes 가 모델에 맞춰 강도를 낮춰 보내면 실제와 다를 수 있다. 실제 값은 관리자 영역의 실행 기록에 남는다.
- **확인 방법**: `MEMBER` 역할의 단계 목록 응답을 보는 backend 테스트와 `web/test/browser/model-choice.spec.ts`.
