## ADR-007: 에이전트가 모델과 도구를 함께 정한다

- **status**: `accepted`
- **결정**: 사용자를 profile 에 직접 붙이지 않고 `agent` 를 사이에 둔다.
  에이전트 하나가 Hermes profile 하나를 가리키고, 그 profile 이 모델과 도구와 페르소나를 정한다.
  사용자는 대화를 시작할 때 쓸 수 있는 에이전트 중에서 고른다.

### 맥락

처음에는 사용자 하나에 profile 하나를 붙였다.
credential 을 격리하기 위한 배치였는데, 가족이 계정 하나를 함께 쓰기로 정하면서
([ADR-002](ADR-002-profile은-나누고-ai-계정은-가족이-함께-쓴다.md)) 그 이유가 없어졌다.

그런데 다른 이유로 profile 을 나눠야 하는 것이 드러났다.
**Hermes 의 도구 집합이 profile 단위다.**

에이전트 정의 저장소의 `career-os` 스킬은 `bun career-os/scripts/...` 를 실행한다.
`terminal` 과 `file` 도구가 필요하다.
그런데 가족이 쓰는 웹 챗에 그 도구를 열면, 챗 창이 곧 홈서버 셸이 된다.
같은 서버에 데이터베이스와 Jenkins 가 함께 있다.

즉 셸이 필요한 작업과 가족 공용 대화를 한 profile 에 담을 수 없다.
사용자 축으로 profile 을 나누면 이 문제를 풀지 못한다.

모델도 같은 자리에서 갈린다.
지금 profile 마다 `model.default` 가 따로 있고, 무거운 작업과 가벼운 작업에 다른 모델이 맞다.

### 대안 기각

- **사용자마다 profile 을 유지하고 도구를 열어 준다.**
  인터넷에 열린 챗 창으로 홈서버 셸을 쓸 수 있게 된다.
  지금은 사용자가 한 명이라 견딜 수 있지만, 가족을 추가하는 순간 되돌리기 어렵다.
- **사용자와 역할의 조합마다 profile 을 만든다.**
  구성원 넷과 역할 여섯이면 profile 이 스물넷이다.
  profile 마다 `.env` 와 gateway 와 포트가 붙어 운영이 감당되지 않는다.
- **요청마다 모델을 지정한다.**
  Runs API 가 받기는 하지만, 같은 대화 안에서 모델이 섞여 비용 기록을 읽기 어려워진다.
  에이전트를 고르는 것이 모델을 고르는 것이 되는 편이 사용자에게도 읽기 쉽다.
- **접근 권한을 별도 연결 표로 둔다.**
  이 결정을 내릴 때는 작업 영역이 `visibility` 와 소유자로 같은 일을 이미 하고 있었다.
  표를 하나 더 두면 같은 규칙이 두 방식으로 표현된다.
  작업 영역을 제거한 뒤에는 에이전트의 `visibility` 와 `owner_user_id` 가 이 책임을 맡는다
  ([ADR-010](ADR-010-작업-영역을-제거하고-에이전트가-그-자리를-갖는다.md)).

### 결과

얻는 것

- 셸이 필요한 에이전트와 가족 공용 에이전트가 한 시스템에 함께 있을 수 있다.
- 에이전트를 고르면 모델과 도구와 페르소나가 함께 정해진다.
- 실행 기록에 어느 에이전트였는지 남아 역할별 사용량과 비용을 볼 수 있다.
- 사용자 하나가 여러 에이전트를 쓸 수 있다. 이전 배치는 하나뿐이었다.

감당할 것

- **공개 범위가 편의 기능이 아니라 보안 통제다.**
  도구가 열린 에이전트를 가족 공개로 두면 그 순간 셸이 열린다.
  그래서 기본값을 두지 않고 만들 때마다 고르게 한다.
  에이전트의 `visibility` 와 `owner_user_id` 가 접근 권한을 정하며,
  작업 영역이 맡았던 공개 범위 규칙을 이어받았다.
- 대화는 시작할 때 에이전트를 고정한다. 중간에 바꾸지 못한다.
  `hermes_session_id` 가 특정 profile 안의 값이라, 바꾸면 그 session 이 가리키는 것이 없어진다.
- profile 을 만드는 일은 웹이 하지 않는다.
  Hermes 는 profile 생성을 CLI 로만 제공하고, 웹 요청이 호스트에서 명령을 실행하는 경로를 만들지 않는다.
  웹은 이미 있는 profile 을 에이전트로 등록하고 고르는 것까지만 한다.
- 모델 이름을 손으로 적지 않는다.
  Hermes 에 물어 맞춘다. 두 곳에 적으면 어긋나고, 어긋나면 환산 비용이 틀린다.
