## ADR-20261009: 도구 사용 요청은 따로 저장하고 관리자는 반영을 확인한 뒤 승인한다

- **status**: `accepted`
- Date: 2026-10-09

### 결정

에이전트의 주인이 보이는 ADMIN 등급 도구의 사용을 요청한다.
도구 등급과 직접 변경 권한은 바꾸지 않는다.
요청은 `agent_toolset_request`에 저장하고 에이전트 행 잠금으로 요청과 결정을 직렬화한다.
기본 profile의 도구 기본값은 이 결정이 정하지 않는다.

| 상태 | 뜻 |
| --- | --- |
| `PENDING` | 관리자 확인을 기다린다 |
| `APPROVED` | Hermes가 도구를 반영한 것을 확인했다 |
| `REJECTED` | 관리자가 한 줄 사유를 남겨 거절했다 |
| `CANCELLED` | 요청자가 대기 요청을 취소했다 |
| `EXPIRED` | 결정할 때 주인, 그룹, 접근 권한, 도구 노출이나 공개 범위가 달라 요청할 수 없었다 |

같은 그룹, 에이전트, 요청 사용자, 도구의 PENDING은 하나만 둔다.
반복 요청은 같은 공개 식별자를 돌려주며 관리자 알림을 다시 만들지 않는다.
DB 유일 제약은 `pending_slot`을 대기 중에만 1로 채우고 끝난 뒤 NULL로 비워 구현한다.
끝난 요청은 이력으로 남기며 다시 요청할 수 있다.
자동 시간 만료는 두지 않고, 바뀐 조건은 결정할 때 만료로 확정한다.
취소와 만료는 이미 켠 도구를 끄거나 승인한 권한을 회수하지 않는다.

관리자 권한과 로그인 차단 여부는 결정할 때 현재 사용자 줄과 로그인 판정으로 다시 확인한다.
요청자가 지금 주인인지, 같은 그룹인지, 에이전트를 지우지 않았는지,
커넥터 관리 에이전트가 아닌지, 도구가 ADMIN 등급이며 보이는지, 비공개 조건을 지키는지도 다시 본다.
에이전트 잠금 아래 현재 활성 목록에 요청한 이름을 더하고 기존 `AgentToolService`의 관리자 쓰기를 부른다.
올린 스킬의 비밀 요청과 Hermes 실행 공간 조건, 저장 뒤 실제 반영 확인도 같은 경로를 거친다.

Hermes 장애, 실행 공간 미준비, 스킬의 비밀 요청이나 미반영은 요청을 PENDING으로 남긴다.
반영 뒤 DB 저장이 실패하면 Hermes에 이미 켜진 도구가 남을 수 있다.
재승인은 현재 활성 목록을 다시 읽고 전체 설정을 다시 검증한 뒤 같은 도구를 중복 없이 반영한다.
결정과 요청자 알림은 같은 DB 트랜잭션이므로 실패한 결정의 결과 알림은 남지 않는다.
끝난 요청을 다시 결정하면 저장된 결과를 돌려주며 설정과 알림을 반복하지 않는다.

새 요청과 같은 트랜잭션에서 같은 그룹의 차단되지 않은 관리자들에게 `TOOLSET_REQUESTED` 알림을 만든다.
결정과 같은 트랜잭션에서 요청자에게 `TOOLSET_REQUEST_DECIDED` 알림을 만든다.
커넥터 호출 승인을 뜻하는 `APPROVAL_REQUESTED`는 재사용하지 않는다.
알림 사건은 기존 규칙대로 커밋 뒤에만 보낸다.

일반 화면에는 「사용 요청」과 「관리자가 확인하면 켜져요」를 쓴다.
관리자 알림은 에이전트의 관리자 상세로 이어지고 그 화면에서 승인하거나 거절한다.
지운 에이전트의 요청은 별도 관리자 요청 화면에서 확인하고 만료할 수 있다.
요청자는 에이전트 도구 목록과 결과 알림에서 상태와 사유를 읽는다.

### 배경과 대안

일반 사용자가 필요한 ADMIN 도구를 직접 켜면 기존 도구 권한 경계를 우회한다.
관리자가 따로 연락을 받고 에이전트를 고치는 방식은 요청 상태와 사유를 남기지 못한다.
따라서 요청 이력을 권한 설정과 분리하고 현재 조건을 확인한 관리자만 설정을 바꾼다.

기존 커넥터 승인 줄은 실행과 도구 호출에 묶인다.
에이전트의 다음 실행에 적용할 도구 설정은 수명과 대상이 달라 별도 요청 표를 둔다.
승인 상태부터 적고 Hermes에 쓰는 대안은 실제로 켜지지 않은 도구를 승인됐다고 알리므로 기각한다.

### 검증

동시 요청과 반복 요청, DB의 대기 유일 제약과 이력 보존, 다른 사용자와 그룹 접근을 검사한다.
요청 뒤 숨김, 삭제, 주인과 그룹 변경, 사용자 차단, 공개 범위 변경과 관리자 권한 상실도 검사한다.
Hermes 장애와 미반영, 비밀 요청 스킬과 실행 공간 실패, 반영 뒤 DB 롤백과 재승인을 확인한다.
브라우저에서는 두 폭에서 요청, 승인, 거절 사유, 취소, 숨김과 삭제 뒤 만료, 알림 이동을 반복 검사한다.
