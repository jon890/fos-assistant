## ADR-039: 외부 서비스 연결은 사용자별 전용 에이전트로 실행한다

- **status**: `accepted`
- **결정**: 가계부 연결은 사용자마다 전용 profile과 비공개 에이전트를 만든다.
  토큰은 해당 profile의 `.env`에만 저장한다.
  신뢰된 plugin 이름으로 MCP와 persona를 설치하고 셸, 파일, 스킬 수정 도구를 닫는다.
  연결용 에이전트는 주인과 관리자 모두 일반 설정 편집과 공개, 삭제 경로를 쓰지 않는다.
  등록과 확인, 해제는 연결 화면에서 한다.
- **더해진 부분**: 아래 세 결정이 이 결정 위에 얹혔다. 「셸, 파일, 스킬 수정 도구를 닫는다」 는 그대로다.
  - 커넥터를 `connector.json` 으로 선언하는 일반 흐름: [ADR-043](ADR-043-커넥터는-plugin-의-connector-json-으로-선언하고-control-plane-은-범용-흐름만-갖는다.md)
  - 연결용 에이전트가 켤 수 있는 읽기 전용 이미지 도구 예외: [ADR-044](ADR-044-커넥터-manifest-는-읽기-전용-이미지-도구만-열-수-있다.md)
  - Control Plane MCP 와 Memory 를 받지 않는 경계: [ADR-045](ADR-045-커넥터-에이전트는-자기-mcp-서버만-받고-memory-와-control-plane-도구를-받지-않는다.md)
- **맥락**: 가계부가 첫 외부 SaaS 연결이다.
  사용자가 자신의 연동 토큰을 화면에서 등록하기로 정했다.
  일반 에이전트에 토큰과 도구를 더하면 다른 용도의 셸과 파일 도구로 비밀값에 접근하거나,
  에이전트를 공개해 다른 사용자가 토큰 주인의 권한을 쓰게 될 수 있다.
  [ADR-033](ADR-033-사용자가-에이전트를-만들고-공개해도-만든-사람이-관리한다.md)의 일반 편집 권한에는
  연결용 에이전트만 예외를 둔다.
- **대안 기각**:
  - 기존 기본 profile에 가계부 도구를 더하면 도구와 토큰을 가계부 대화로 한정하지 못한다.
  - 임의 plugin 설치 UI는 첫 연결에 필요한 범위보다 넓고 실행할 코드와 환경 값을 사용자 입력으로 받게 된다.
  - 토큰을 DB에 저장하면 비밀값을 DB에 넣지 않는 제품 계약을 어긴다.
  - `skills` toolset을 켜면 스킬 수정 기능까지 열리므로 신뢰된 본문을 persona에 설치한다.
- **결과**:
  - 얻는 것: 관리자의 서버 접근 없이 사용자가 자기 연결을 등록하고, 다른 사용자와 토큰을 나눈다.
  - 감당할 것: DB 상태와 Hermes env, MCP 프로세스는 하나의 트랜잭션이 아니다.
    외부 반영 실패는 비활성 상태로 남기고 다시 등록하거나 해제한다.
    DB 커밋 실패나 이미 떠 있는 MCP 프로세스의 토큰 교체는 운영에서 상태를 확인해야 한다.
    공유 gateway 재시작은 다른 실행에도 영향을 주므로 사용자 요청에서 실행하지 않는다.
    API와 상태 계약은 [커넥터 연결](../connectors.md)이 갖는다.
