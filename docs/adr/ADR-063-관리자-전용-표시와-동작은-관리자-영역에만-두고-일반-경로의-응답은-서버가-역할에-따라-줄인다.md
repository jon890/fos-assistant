## ADR-063: 관리자 전용 표시와 동작은 관리자 영역에만 두고 일반 경로의 응답은 서버가 역할에 따라 줄인다

- **status**: `accepted`
- **결정**: 관리 동작과 관리자 전용 표시는 `/admin` 아래의 관리자 영역에만 둔다. `ADMIN` 역할도 일반 화면에서는 `MEMBER` 역할 사용자와 같은 것을 본다.
  일반 화면에서 관리자 영역으로 가는 입구는 사이드바 맨 아래 줄의 「관리자」 하나다.
  화면이 `MEMBER` 역할에게 그리지 않는 내부 값(금액, 모델, 토큰, 시각 구간, 설정 구분값)은 Control Plane 이 일반 경로의 응답에서도 뺀다.
  관리자 API 경로(`/api/v1/admin/**`)와 그 권한 검사는 그대로다.
- **맥락**:
  - 관리 화면의 링크와 관리자 전용 표시가 일반 화면 곳곳에 섞여 있었다. 사용자 관리는 사이드바 메뉴의 한 줄이었고, 그룹 모델 설정은 대화 입력창의 설정 창 안에, 에이전트 관리는 에이전트 상세의 아래쪽 절에, 커넥터 연결 확인은 연결 목록 아래에 있었다.
  - 2026-10-02 관리자가 새 사용자를 더하려다 그 화면으로 가는 길을 찾지 못했다. 관리 작업을 어디서 시작하는지가 한 자리로 정해져 있지 않았다.
  - 관리자는 제품을 쓸 때 다른 사용자가 보는 화면을 그대로 보고 싶어 한다. 관리자에게만 보이는 값이 섞여 있으면 다른 사용자의 화면이 어떤지 자기 화면으로 알 수 없다.
  - 금액과 모델과 토큰은 화면에서만 가렸다. `MEMBER` 역할 사용자가 브라우저의 개발자 도구로 자기 실행의 그 값을 볼 수 있었다. 도구 `detail` 은 이미 서버가 뺀다([ADR-038](ADR-038-도구의-명령-원문은-관리자에게만-보내고-사용자에게는-사람-말로-보인다.md)).
- **대안 기각**:
  - **입구만 눈에 띄는 자리로 옮긴다.** 관리 화면이 일반 화면의 절로 남아 관리자는 여전히 다른 사용자와 다른 화면을 본다.
  - **일반 화면에 「관리자로 보기」 전환 단추를 둔다.** 같은 주소가 상태에 따라 다른 것을 보여 캡처와 주소 공유로 조사하기 어렵다. 전환을 켜 둔 채 쓰면 지금과 같아진다.
  - **대화 화면의 원본 보기와 오류 코드는 남긴다.** 대화 중에 원인을 바로 볼 수 있지만 관리자의 대화 화면이 다른 사용자와 달라진다. 실패한 실행은 관리자 영역의 실행 기록에서 연다.
  - **관리자 영역이 쓰는 조회 경로를 `/api/v1/admin/**` 로 새로 만든다.** 같은 조회가 두 벌이 된다. 일반 경로가 요청자의 역할을 보고 줄이면 한 벌로 된다.
  - **`MEMBER` 응답에서 오류 코드까지 뺀다.** 화면이 코드를 사람 말 문구로 바꾸고 분기에도 쓴다. 빼면 모든 실패가 같은 문구가 된다. 코드는 값의 종류가 정해진 이름이고 내부 경로나 금액이 아니다.
- **결과**:
  - 얻는 것:
    - 관리 작업의 시작점이 한 자리다. 대화 목록 길이나 화면 높이와 상관없이 보인다
    - 관리자가 일반 화면에서 보는 것이 다른 사용자가 보는 것과 같다
    - `MEMBER` 역할 사용자는 개발자 도구로도 금액과 모델과 토큰을 보지 못한다
  - 감당할 것:
    - 관리자가 대화하다 실패 원인을 보려면 관리자 영역으로 옮겨 가 그 실행을 찾아야 한다
    - 관리자 본인의 `/usage` 가 실행 건수만 보인다. 금액은 `/admin/usage` 에서 본다
    - 화면에 역할로 갈리는 표시를 더할 때 그것이 관리자 영역의 것인지 먼저 정한다. 일반 화면에 `ADMIN` 만 보는 표시를 새로 만들지 않는다
    - 일반 경로의 응답에 내부 값을 더할 때 `MEMBER` 역할에게 뺄지 함께 정하고 [`backend/conversation.md`](../backend/conversation.md) 의 표에 적는다
    - 서버가 권한을 강제하는 일반 화면의 동작(그룹 공용 기억 쓰기, 그룹 공개 에이전트 고치기)은 일반 화면에 남는다. 「같은 것을 본다」 는 관리 표시와 내부 값에 대한 것이고 서버 권한을 줄인다는 뜻이 아니다
- **적용 범위**: 화면의 구조와 옮긴 것의 목록은 [`frontend/structure.md`](../frontend/structure.md) 의 「관리자 영역」 절, 틀과 입구는 [`frontend/shell.md`](../frontend/shell.md), 빼는 값의 표는 [`backend/conversation.md`](../backend/conversation.md) 의 「역할에 따라 응답에서 빼는 값」 절이 갖는다.
