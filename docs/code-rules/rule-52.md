# rule-52

주석·문서·도메인 용어는 저장소 언어 규칙을 따른다.

검사: [문서 참조](../../test/unit/doc-code-references.test.ts), [리뷰](../../.github/workflows/code-review-prompt.txt)

## 까닭

읽는 사람이 같은 개념을 다른 말로 오해하지 않게 한다.

## 예외와 검토 범위

식별자·타입·명령·경로는 원문을 쓴다.
README.md만 영어이며 README.ko.md와 맞춘다.
기존 영어 주석은 해당 파일을 고칠 때 옮긴다.
구체 용어 표는 루트 AGENTS가 갖는다.

## 이 저장소의 사례

[README.ko.md](../../README.ko.md)에서 확인한다.
README.ko.md는 영어 README와 같은 제품 내용을 한국어로 제공한다.
