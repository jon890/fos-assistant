# rule-60

브라우저 테스트는 빌드·실행 환경을 분리하고 타이밍 가정을 두지 않는다.

검사: [리뷰](../../.github/workflows/code-review-prompt.txt)

## 까닭

빌드 때 굳은 설정과 우연한 대기 시간이 테스트 결과를 좌우하지 않게 한다.

## 예외와 검토 범위

운영 이미지처럼 자리표시자로 빌드하고 실행 때 값을 준다.
고정 대기나 한 화면 폭의 우연에 기대지 않는다.
독립성·포트·기다림은 browser README를 따른다.

## 이 저장소의 사례

[README.md](../../test/browser/README.md)에서 확인한다.
browser README는 개발 서버와 빌드 서버의 차이 및 테스트의 독립성을 설명한다.
