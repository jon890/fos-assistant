## ADR-20261120 / agent-service-writes: 에이전트는 되돌릴 수 있는 서비스 쓰기를 바로 하고 지우기는 승인 카드로 미루며, 사람이 없는 실행에도 같게 연다

- **status**: `accepted`
- Date: 2026-11-20
- 스펙은 [서비스 개념 스펙](../../../docs/features/service-concepts/spec.md)(DECISION4, DECISION5, DECISION6, DECISION10, DECISION31, DECISION32), 구조는 같은 폴더 [`design.md`](../../../docs/features/service-concepts/design.md) 의 「PR2 예약 작업 도구」 가 갖는다.
- [ADR-082](../../../docs/adr/ADR-082-먼저-살펴보기의-쓰기-도구는-관리자가-에이전트마다-켜고-커넥터-쓰기는-승인-카드로-보낸다.md) 의 「살펴보기의 쓰기는 관리자가 켠다」 를 Control Plane 의 서비스 쓰기 도구에도 쓴다. [ADR-085](../../../docs/adr/ADR-085-매일-깨우기는-예약-작업을-다시-쓰고-다섯-칸-보고를-지금-화면에-올린다.md) 의 할 일 제안 규칙은 PR3 이 이 결정 위에서 바꾼다.

### 결정

**에이전트가 요청자의 서비스 데이터를 바꾸는 도구는 되돌릴 수 있는 것만 바로 하고, 되살릴 수 없는 것은 승인 카드로 미룬다.**

| 동작 | 처리 | 까닭 |
| --- | --- | --- |
| 예약 작업 만들기, 고치기, 멈추기, 다시 켜기 | 바로 한다 | 사용자가 화면에서 되돌릴 수 있다 |
| 예약 작업 지우기 | 승인 카드. 승인하면 Control Plane 이 저장한 인자로 한 번 하고 알림 줄만 남긴다 | 지운 작업은 화면에서 되살릴 길이 없다 |
| 할 일 바로 만들기와 끝내기(PR3) | 사용자가 직접 시킨 것만 바로 한다 | 잘못 만든 할 일은 화면에서 끝내고, 잘못 끝낸 할 일은 대화에서 같은 제목과 기한으로 다시 적는다 |
| 기억 지우기(PR3), 연결 붙이기(PR4) | 승인 카드 | 지우면 되살릴 수 없고, 붙이기는 에이전트의 권한을 넓힌다 |

**사람이 지켜보지 않는 실행(예약 작업의 실행, 먼저 살펴보기, 맡긴 실행)도 같은 도구를 같은 규칙으로 쓴다.**
먼저 살펴보기는 바로 바꾸는 도구를 관리자가 그 에이전트에 쓰기를 켠 경우에만 받고, 승인 카드만 띄우는 도구는 늘 받는다.
맡긴 실행의 카드는 루트 실행의 대화에 뜬다.

**승인 카드는 새 표 없이 플러그인 승인 줄(`connector_action`)에 둔다.** `connector_id` 가 `fos-assistant` 이고 도구 이름과 등록 이름이 맞는 줄이다(`ControlPlaneActions`). 상시 허락과 대화 허락이 없다.

### 맥락

사용자는 에이전트가 가능한 한 직접 처리하기를 골랐다(스펙 DECISION2). 권장안(사람이 보낸 실행에서만 바로 쓰기)이 아니라 사람이 없는 실행에도 같게 여는 것을 골랐고, 바깥 글에 숨은 지시로 예약 작업이 생겨 매회 비용이 드는 위험을 알고 골랐다(스펙 DECISION10).
그 위험의 상한은 예약 작업의 지금 한도(사용자당 10개, 최소 15분, 하루 48번)와, 바깥 글을 가장 많이 읽는 먼저 살펴보기의 관리자 스위치다.

### 대안 기각

- **사람이 보낸 실행에서만 쓰기 도구를 준다**: 사용자가 고르지 않았다. 예약 작업의 지시문이 시킨 일을 그 실행에서 하지 못한다
- **모든 쓰기를 승인 카드로 미룬다**: 「직접 처리」 의 뜻과 어긋나고, 되돌릴 수 있는 일까지 매번 사람을 부른다
- **승인 카드용 표를 새로 만든다**: 표를 늘리지 않는다는 사용자 결정(2026-11-01)과 어긋나고, 카드 자리와 알림, 만료 흐름을 다시 만들어야 한다

### 결과

- 새 서비스 쓰기 도구를 더할 때 위 표의 어느 줄인지 먼저 정한다
- 먼저 살펴보기에서 받는 도구는 `McpController` 의 세 목록(`CHECK_TREE_TOOLS`, `CHECK_TREE_WRITE_TOOLS`, `CHECK_TREE_DIRECT_TOOLS`)이 갖는다
- 사용자가 직접 시킨 일인지는 모델의 인자와 실행 출처를 함께 본다. 판정은 [`design.md`](../../../docs/features/service-concepts/design.md) 의 「PR3 할 일과 기억 도구」 가 갖는다
