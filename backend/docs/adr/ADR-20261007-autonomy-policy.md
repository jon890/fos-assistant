## ADR-20261007: 행동 수준은 Control Plane 의 결정적 규칙이 정하고 첫 자동 실행은 읽기 전용 살펴보기 한 번이다

- **status**: `accepted`
- Date: 2026-10-07

### 맥락

가치 판단은 받아들인 문제 후보의 축별 판단과 추천 순서를 남긴다([ADR-20261007 / value-evaluation](../../../docs/adr/ADR-20261007-value-evaluation.md)).
그 판단이 높다고 해서 그 일을 사람 없이 해도 되는 것은 아니다.
문제 후보의 행동(`actionText`)은 모델이 쓴 자유 글이고, 부작용 힌트(`sideEffect`)도 모델이 쓴 값이다.
Control Plane 은 그 글이 실제로 어떤 도구를 부를지 알 수 없다.

### 결정

**`AutonomyPolicy` 가 후보마다 `IGNORE`, `SURFACE`, `ASK_APPROVAL`, `EXECUTE` 가운데 하나를 정한다.**
입력은 저장된 평가, 지금의 후보 줄, 원천 살펴보기, 에이전트, 설치 설정, 사용자 동의다. 모델을 부르지 않는다.
같은 입력이면 같은 수준과 같은 까닭 코드가 나온다. 판정마다 수준, 까닭 코드, 쓴 입력을 한 줄로 남긴다.

**모델의 값은 수준을 낮추기만 한다.**
확신이 높거나 부작용 힌트가 `NONE` 이라는 사실은 실행 조건의 하나일 뿐 충분 조건이 아니다.
`EXTERNAL`, `INTERNAL`, 모르는 값은 모두 승인 쪽으로 보낸다.

**`EXECUTE` 는 후보의 글을 실행하는 것이 아니다.**
그 에이전트의 읽기 전용 살펴보기를 한 번 더 시작하는 것이다(`CheckTrigger.AUTONOMY`).
읽기 경계는 지금처럼 Control Plane 이 강제한다. toolset 허용 목록과 커넥터 도구 판정의 `READ_ONLY` 가 쓰기를 막는다.
그 에이전트에 「먼저 살펴보기에 쓰기 도구 허용」 이 켜져 있으면 판정도 시작도 거절한다.
그래서 실행의 부작용은 후보의 글이 아니라 실행 경로가 정한다.

**자동 실행은 둘 다 켜져야 한다.** 설치 설정 `assistant.autonomy.execution-enabled` 와 사용자 동의 표다. 둘 다 기본은 꺼짐이다.

**`ASK_APPROVAL` 은 새 승인 줄을 만들지 않는다.**
실제 외부 쓰기는 기존 커넥터 승인 경로([ADR-050](ADR-050-커넥터-쓰기는-control-plane-이-승인-줄을-저장하고-승인한-인자로-한-번만-실행한다.md))만 거친다.
이번 판정은 「사람의 승인 없이는 아무것도 하지 않는다」 를 기록한다.

**한 원천 살펴보기에서 자동 실행은 한 번이다.** 실행 키를 유일 제약으로 두고 실행 전에 저장한다.
자동 실행으로 시작한 살펴보기는 다시 자동 실행의 원천이 되지 못한다.

**자동 실행으로 시작한 살펴보기는 사용자에게 바로 알리지 않는다.**
답과 보고와 발견을 남기지 않고 문제 후보만 저장한다. 그 후보는 다시 가치 판단과 이 정책을 거쳐야 사용자에게 갈 수 있다.

### 버린 대안

- **부작용 힌트가 `NONE` 이면 후보의 글을 Hermes 에 그대로 맡긴다**: 힌트는 모델이 쓴 값이다. 웹 글에 속은 모델이 `NONE` 으로 적으면 쓰기가 나간다.
- **판단의 확신이 높으면 승인을 건너뛴다**: 모델이 권한을 넓히는 길이 된다.
- **`ASK_APPROVAL` 에 새 승인 카드를 만든다**: 승인할 도구와 인자가 아직 없다. 인자 없는 승인은 사람이 무엇에 동의했는지 남기지 못한다.
- **실행이 실패하면 자동으로 다시 시작한다**: 같은 원천에서 실행이 두 번 나갈 수 있다. 실패한 원천은 다시 실행하지 않는다.

### 감당할 것

- 자동 실행은 후보 하나를 겨냥한 조사가 아니라 그 에이전트의 일반 살펴보기다. 후보를 실행 입력에 넣는 일은 다음 단계에서 정한다.
- `SURFACE` 와 `ASK_APPROVAL` 은 판정과 기록뿐이다. 사용자 화면은 이번에 만들지 않는다.
- 판정과 실행 사이에 관리자가 쓰기 허용을 켜면 시작 단계가 다시 거절한다. 판정 기록은 그때의 입력을 남긴다.
- 실행 키를 저장한 뒤 시작 전에 서버가 멈추면 그 줄은 `PENDING` 으로 남고 다시 실행하지 않는다.

### 근거와 결과

세부 규칙과 까닭 코드, 저장 칸은 [행동 정책](../../../docs/backend/autonomy-policy.md)이 갖는다.
